# 桌面工具、草稿附件與分類檢查（v1.131.0）

## 浮動工具偶爾無法置頂

程式檢查找到三項可改善的原因：兩個視窗原先每兩秒重設置頂，可能互相改變前後順序；原生選單狀態殘留可能抑制置頂同步；遠端桌面／螢幕解像度改變後，已開啟視窗可能停在可見範圍外。這是依程式路徑推斷，未在使用者的 Windows 裝置重現。

現在只在原生狀態不符時修復；主程式重新叫出浮動工具時會清除選單狀態、重建置頂層級並把視窗移回可見工作區。結束原生選單也會修復一次，正常的兩秒檢查不再持續搶前後順序。若設定本來關閉置頂，仍尊重該設定。

兩個獨立置頂視窗仍有前後順序，不可能各自永遠蓋在另一個上方。建議讓工作情境使用程式內面板，或關閉其「保持置頂」，只讓浮動工具常駐桌面。

## 工作情境的兩種使用方式

設定 → 浮動工具 → 工作情境顯示方式：

| 選項 | 行為與情境 |
| --- | --- |
| 桌面浮動 | 獨立視窗；適合在其他程式間切換客戶，保留 24–64px 圖示、懸停展開、固定展開與獨立置頂 |
| 程式內面板 | 按情境入口時回到主程式，以精簡對話面板顯示；適合不希望桌面有兩個浮窗的人 |

變更模式會隱藏原桌面面板；有未完成參數或操作時先完成，避免丟失內容。程式內面板關閉時，未完成輸入會要求確認。顯示模式會保存，重啟後沿用。

面板預設約 360 × 480px；舊的超寬桌面尺寸會回復精簡尺寸。追蹤檔案採名稱、大小與日期的緊湊清單，搜尋同時比對檔名與路徑，每頁 50 項。點名稱開啟，點「⋯」查看完整路徑、所在位置或複製路徑；不再提供桌面寬版表格及跨頁勾選。完整欄位、排序及批次操作仍在 Everything 追蹤頁。

## 草稿附件

新貼上的圖片以「貼上的圖片 1.png」「貼上的圖片 2.png」依序命名，畫面顯示相同編號。刪除中間一張不重編其他圖片；儲存時避免覆蓋同名檔案。既有 UUID 圖片仍可讀取，不批次重新命名。

新複製／搬移到草稿儲存區的檔案、資料夾與圖片共用該草稿根目錄，不再額外建立 `files/`。拖入的資料夾仍保留其自身目錄與內容。同名附件沿用既有衝突處理。舊 `files/` 目錄不自動搬移，確保已有連結繼續有效。只建立原路徑連結的附件不會因此複製。

## 作業中心移除

移除工具入口、指南、功能搜尋及佇列／歷程操作 IPC。保留一般批次改名、搬移、進度取消與上一批復原；舊資料不破壞性清除。移除作業中心不等於刪除磁碟檔案。

## 我的收藏與頁面分類建議

目前收藏頁混合「保存入口」與「動態搜尋」，使用者容易分不清楚資料屬於哪裡。建議 Everything 獨立為「檔案搜尋／追蹤」頁；「檔案與資料夾」及「工作區紀錄與表格」仍是收藏，保留在我的收藏內，以分頁區別。拆成三個頂端頁面會增加導覽負擔，沒有必要。本次保留既有導覽，以下為後續整理建議。

| 類別 | 建議入口 | 理由 |
| --- | --- | --- |
| 總覽 | 首頁 | 最近資料與常用入口 |
| 工作資料 | 資料工作區、日曆／看板、查看紀錄 | 建立、安排及閱讀同一批工作區資料 |
| 尋找與收藏 | 全域搜尋、我的收藏、檔案搜尋／追蹤 | 清楚區分 app 資料搜尋、保存入口及磁碟索引搜尋 |
| 工具 | 檔案工具、工具箱 | 批次檔案處理與輔助工具 |
| 桌面快捷 | 浮動工具、工作情境 | 同一批資料的快捷入口，不是新的資料庫 |
| 系統 | 設定、資訊 | 偏好、指南及版本 |

工具箱主要保留情境包、參數範本、追蹤變更、離線 OCR、備份；路徑修復、整理規則與文件預覽放其他工具。追蹤變更負責比較快照，Everything 追蹤負責搜尋結果，應以連結串接並標明用途。

## 遠端桌面快捷鍵排查

部分系統組合鍵不作用是 RDP 設定或環境限制，不能把所有自訂快捷鍵失效視為正常。先確認 Bulk File Studio 在要操作的遠端 Windows 工作階段執行，並在設定 → 快捷鍵檢查註冊／衝突及專注模式。

Windows 的 mstsc：顯示選項 → 本機資源 → 鍵盤 → 套用 Windows 按鍵組合，選「在遠端電腦上」，或使用「僅在使用全螢幕時」並切到全螢幕。這個選項主要控制 Windows 系統組合鍵，並不保證所有自訂 Ctrl+Alt 快捷鍵都會通過。本機同時執行並註冊相同按鍵的程式可能先攔截；可暫停本機快捷鍵再測試。複製與貼上還受剪貼簿重新導向及目標程式焦點影響。

Microsoft 文件另列出巢狀 RDP／RemoteApp 的快捷鍵限制。若只有快捷鍵失敗但按鈕可用，優先查傳遞與註冊；若按鈕也失敗，應查程式狀態及診斷紀錄。

官方參考：[RDP 快捷鍵與鍵盤設定](https://learn.microsoft.com/en-us/windows/win32/termserv/terminal-services-shortcut-keys)、[PowerToys Always On Top 相容性](https://learn.microsoft.com/en-us/windows/powertoys/always-on-top)、[Electron BrowserWindow API](https://www.electronjs.org/docs/latest/api/browser-window)。

## 驗證範圍

自動測試涵蓋置頂同步與顯式恢復、畫面外位置、顯示模式及來源驗證、未儲存輸入保護、附件命名／碰撞／回滾、精簡清單與作業中心入口移除。check:app 盤點全部來源、頁面、工具與設定；這是靜態契約及模擬回歸，不等同所有功能逐項 Windows 驗收。實際 RDP、DPI、多螢幕、Windows 原生置頂、Everything、OCR、外部貼上與 EXE 仍需實機確認。

本次驗證：`npm test` 1,223 項通過、零失敗；`npm run check:app` 通過（223 個來源、10 頁、11 個工具、29 個功能目錄項目、264 個設定）；更新紀錄與兩份離線指南一致性檢查通過。

合併前審查修正：程式內工作情境開啟工作集時，確認對話框改由主視窗擁有；桌面模式仍使用獨立情境視窗。新增回歸涵蓋從未開過桌面視窗、取消確認及模式來回切換。
