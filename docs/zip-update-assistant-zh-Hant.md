# ZIP 更新助手（v1.135.0）

## 開啟與導覽

頂部常用入口依序為首頁、資料工作區、我的收藏、Everything 追蹤及日曆／看板。
「工具」選單集中 ZIP 更新助手、檔案工具、全域搜尋、查看紀錄及工具箱；設定／資訊仍在右側齒輪選單。

## 將更新 ZIP 套用到現有資料夾

1. 點「工具 → ZIP 更新助手」。選擇 ZIP 或將一個 ZIP 拖進上方區域。
2. 選擇目標資料夾。比較前不會寫入目的地。
3. 「ZIP 來源根目錄」預設保留完整層級。若目標已是 ZIP 內同名資料夾，選該來源根目錄，以免重複多加一層。
4. 按「比較檔案」。預覽列出 ZIP 路徑、內容狀態、大小及完整目標路徑。相同內容預設略過；無法處理的項目不可勾選。
5. 核對新增與覆寫項目，可搜尋路徑、篩選狀態、逐項勾選；全選只處理符合目前篩選的可更新項目，跨頁亦包含。
6. 按「確認套用」，再確認目的地與數量。原有檔案先備份，之後逐項更新；ZIP 沒有的目標檔案一律保留。
7. 下方結果列出已套用、失敗及未執行項目。「最近更新與還原」可重新查看結果、開啟目標或備份資料夾。

## 常用位置

成功讀取 ZIP 後自動記住其來源資料夾。也可按「加入常用來源資料夾」預先加入位置；在「從常用位置選 ZIP」選一個資料夾，即會從該位置開啟 ZIP 選擇器。
最近的 ZIP 來源及目的地各保存 10 個，重新啟動後仍可使用。

## 備份、取消與還原

- 原檔、目標、內容指紋與逐項操作記錄保存在應用程式的 ZIP 更新記錄資料夾。從「備份／記錄」直接開啟；原檔使用 `.bak`，由 `manifest.json` 對應原路徑。
- 最近 20 次更新顯示在清單；較舊備份不會自動刪除。
- 「停止後續項目」會停止後續工作；已完成的項目保留並列入更新記錄。整批更新不是原子交易。
- 還原會把覆寫檔案恢復原內容，並移除該次新增且內容仍一致的檔案。新增的空資料夾保留。
- 更新後又被修改的檔案不會被還原覆蓋，會列出衝突。其他項目仍可還原。
- 原生確認框選取消不會套用更新，也不會消耗預覽；仍可調整勾選後再確認。
- 預覽有效期 30 分鐘。更換 ZIP、目標或來源層級後需要重新比較；寫入前會再次核對目標，避免覆蓋預覽後的修改。
- ZIP 讀取後使用經校驗的來源快照；若原 ZIP 隨後更新，請重新選取以刷新。

## 支援範圍

ZIP 檔案上限 128 MB，單檔解壓上限 128 MB、總解壓上限 512 MB、最多 5,000 個項目。先檢查目錄，再以串流解壓、校驗 CRC32，並以 SHA-256 比較內容。
第一版使用本機完整路徑，不接受直接 UNC 網路或裝置路徑。ZIP64、加密／分卷 ZIP、連結、Windows 不合法或無法辨識的檔名、重複／大小寫衝突路徑會明確拒絕。RAR、7z 不在此功能範圍。

## 浮動工具操作修正

- 懸浮球的圖示填滿 58 × 58 DIP 的圓形區域，不再繼承側邊工具列的內距與外框。
- 一般點擊不會提前將滑鼠捕捉至父層；拖曳超過門檻才開始移動。
- 可直接點擊未啟用的工具，啟用該分頁並開啟，而非留下不能按的圖示。
- 開啟「離開或失焦時自動收合」後，新式入口在滑鼠離開約 650 ms 或視窗失焦約 250 ms 後收合。偵測在主程序進行，不依賴失焦頁面的計時器。
- 已固定的快捷面板不自動收合。開著對話框／選單、正在編輯工作情境或處理檔案時，也會暫停收合。
- 切換到另一個新式入口時，預設開啟自動收合；之後仍可自行關閉。現有未切換模式的偏好沿用，可從浮窗設定啟用。

## 驗證

回歸測試包含 ZIP 內容比較、根目錄映射、選取子集、備份與重啟還原、目標／來源快照變更、還原衝突、路徑／連結／解壓限制、取消、記憶位置及 UI 操作；另包含浮窗離開、失焦、固定保護及點擊捕捉。

本機 Chromium 預覽受環境政策封鎖，未完成視覺驗收。Windows Electron 的原生視窗形狀、多螢幕／DPI、檔案鎖定及 Windows EXE 仍需實機驗收。
