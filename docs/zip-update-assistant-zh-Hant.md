# ZIP 更新助手（v1.139.0）

## 開啟與導覽

頂部常用入口依序為首頁、資料工作區、我的收藏、Everything 追蹤及日曆／看板。
「更多」選單預設集中 ZIP 更新助手、檔案工具、全域搜尋、查看紀錄及工具箱；設定／資訊仍在右側齒輪選單。

## 將更新 ZIP 套用到現有資料夾

1. 開啟「ZIP 更新助手」，清單會自動刷新。來源預設開啟最近使用的來源位置，首次使用會開啟「下載」；目標帶入最近一次可存取的目標資料夾。
2. 有目標後，按底部「比較最新 ZIP」會重新掃描目前的來源資料夾，再比較按檔案修改時間排序的最新 ZIP。新檔案已出現在來源資料夾時，可直接按此按鈕。若要一併更新目標清單，按同一區的「重新整理清單」。要用其他檔案，可點左側清單、使用檔案選擇器，或拖入一個 ZIP。右側點資料夾可設為目標；按「上層」可回到這次選定根目錄範圍內的父層。
3. 「ZIP 來源根目錄」預設保留完整層級。若目標已是 ZIP 內同名資料夾，選該來源根目錄，以免重複多加一層。
4. 來源與目標就緒後會自動比較，保留位置區的展開狀態。結果顯示完整目標路徑、狀態與大小。比較樹的資料夾預設收合，偏好跨重啟記住。目標外部內容有更新時，可按「重新比較」。
5. 核對新增與覆寫項目，可搜尋路徑、篩選狀態、逐項或整個資料夾勾選。資料夾半選代表僅部分子項被勾選。全選及資料夾勾選只處理符合目前篩選的可更新項目，跨頁與收合中的子項亦包含；不會勾選內容相同或無法處理的檔案。
6. 從底部操作區按「確認套用」，再確認目的地與數量。原有檔案先備份，之後逐項更新；ZIP 沒有的目標檔案一律保留。
7. 按頂端「更新結果／還原」直接查看已套用、失敗及未執行項目；出現失敗或衝突時自動帶到結果。「最近更新與還原」可重新查看結果、開啟目標或備份資料夾。

## 自訂導覽

「工具」已改名為「更多」，因為其中可以放各種工作頁面，不限工具。從「設定 → 外觀與版面 → 導覽列與更多選單」選擇每個頁面直接顯示或收進更多，再按上移／下移調整排列。兩處使用同一順序，設定即時套用、自動儲存、可還原預設，並納入偏好匯出。設定與資訊保留在右側固定入口。

ZIP 頁面亦可選為啟動頁或快捷動作目的地。切到其他頁面再回來會保留目前 ZIP、比較與勾選；執行中會阻止切換，請等待或停止後續項目。

## 常用位置

成功讀取 ZIP 後自動記住其來源資料夾。也可按「加入常用來源資料夾」預先加入位置；在「常用 ZIP 來源位置」選一個資料夾，頁面會列出其中的 ZIP 與子資料夾；點 ZIP 直接讀取，不必再開系統選擇器。
最近的 ZIP 來源及目的地各保存 10 個，重新啟動後仍可使用。目標標題下可按「☆ 儲存目前位置」，最多額外保存 50 個常用目的地，不會因瀏覽其他資料夾而被擠出。下拉清單分為常用與最近使用；選取後按「移除所選位置」，會從這兩組移除相同位置，不刪除實體資料夾、不更改目前目標或比較結果。下次重新選用該路徑時會再次加入最近使用。

來源與目標位置清單都支援名稱篩選與分頁；點「名稱／大小／修改時間」可切換升降冪。比較表的資料夾／檔案、狀態、大小、完整目標路徑亦可排序。三個表各自記住欄位及方向，資料夾和檔案一起排序，比較樹的子項在原父資料夾內排序；搜尋比較結果時暫時展開符合的路徑，清除搜尋後恢復已儲存的收合狀態。

位置瀏覽每次最多列出 1,000 項、最多掃描 10,000 個目錄項目，達上限會提示使用選擇器。ZIP 來源清單只列資料夾與 ZIP，目標清單則列現有內容。返回上層限於這次選定根目錄；要切換磁碟或其他根目錄請使用選擇器。

## 備份、取消與還原

- 原檔、目標、內容指紋與逐項操作記錄保存在應用程式的 ZIP 更新記錄資料夾。從「備份／記錄」直接開啟；原檔使用 `.bak`，由 `manifest.json` 對應原路徑。
- 最近 20 次更新顯示在清單；較舊備份不會自動刪除。
- 「停止後續項目」會停止後續工作；已完成的項目保留並列入更新記錄。整批更新不是原子交易。
- 還原會把覆寫檔案恢復原內容，並移除該次新增且內容仍一致的檔案。新增的空資料夾保留。
- 更新後又被修改的檔案不會被還原覆蓋，會列出衝突。其他項目仍可還原。
- 原生確認框選取消不會套用更新，也不會消耗預覽；仍可調整勾選後再確認。
- 預覽有效期 30 分鐘。更換 ZIP、目標或來源層級後需要重新比較；寫入前會再次核對目標，避免覆蓋預覽後的修改。
- ZIP 讀取後使用經校驗的來源快照；若原 ZIP 隨後更新，請重新選取以刷新。

## 支援範圍

ZIP 檔案上限 128 MB，單檔解壓上限 128 MB、總解壓上限 512 MB、最多 5,000 個項目。先檢查目錄，再以串流解壓、校驗 CRC32，並以 SHA-256 比較內容。
第一版使用本機完整路徑，不接受直接 UNC 網路或裝置路徑。ZIP64、加密／分卷 ZIP、連結、Windows 不合法或無法辨識的檔名、重複／大小寫衝突路徑會明確拒絕。RAR、7z 不在此功能範圍。

## 浮動工具操作修正

- 懸浮球的圖示填滿 58 × 58 DIP 的圓形區域，不再繼承側邊工具列的內距與外框。
- 一般點擊不會提前將滑鼠捕捉至父層；拖曳超過門檻才開始移動。
- 可直接點擊未啟用的工具，啟用該分頁並開啟，而非留下不能按的圖示。
- 開啟「離開或失焦時自動收合」後，新式入口在滑鼠離開約 650 ms 或視窗失焦約 250 ms 後收合。偵測在主程序進行，不依賴失焦頁面的計時器。
- 已固定的快捷面板不自動收合。開著對話框／選單、正在編輯工作情境或處理檔案時，也會暫停收合。
- 切換到另一個新式入口時，預設開啟自動收合；之後仍可自行關閉。現有未切換模式的偏好沿用，可從浮窗設定啟用。

## 驗證

回歸測試包含 ZIP 內容比較、根目錄映射、選取子集、備份與重啟還原、目標／來源快照變更、還原衝突、路徑／連結／解壓限制、取消、記憶位置及 UI 操作；另包含浮窗離開、失焦、固定保護及點擊捕捉。

本機 Chromium 預覽受環境政策封鎖，未完成視覺驗收。Windows Electron 的原生視窗形狀、多螢幕／DPI、檔案鎖定及 Windows EXE 仍需實機驗收。
