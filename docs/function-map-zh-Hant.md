# 功能導覽與整合對照（v1.122.0）

本文件依目前頁面、設定目錄、資料服務及操作入口重新整理功能。完整來源與具名函式索引見 [應用程式功能盤點](app-function-audit.md)，可執行 `npm run check:app` 核對入口／設定／頁面引用。首頁「功能導覽」可搜尋下列任務並前往既有操作頁；首頁提供工作區、Everything 追蹤與浮動快捷三個工作流程入口。這是功能與模組盤點，不代表每個 Windows 原生功能均已完成實機驗證。

Everything 追蹤支援已索引的內網 UNC 共享與 Windows 對應磁碟；共享主機各自驗證並非同步檢查實際檔案類型，略過時顯示原因。共享結果可開啟、定位、複製及收藏；共享改名、搬移及回收維持由檔案總管操作。本機系統圖示與共享一般／資料夾圖示並存。更新時間、工具收合、定時更新摘要及已選數量共用一列，窄視窗換行。

工具箱導覽及內容容器使用主題 panel 背景、邊框與輕陰影，選取工具以強調色邊線標示；浮動快捷表單的多行文字欄位支援預設內容、預覽、儲存及連續新增，保留多行文字。

Everything 追蹤以 Shift＋左鍵選取範圍時會抑制瀏覽器文字反白，一般拖曳選字維持可用；修改日期保留右側間距，隱藏複製操作欄也不影響最後資料欄的正常留白。

Everything 追蹤預設於檔名儲存格內單項改名，Enter 確認、Esc／離開取消；設定 → 收藏可選對話框。編輯中暫停更新、錯誤保留輸入，沿用既有來源檢查與衝突保護。左側標籤跨重啟保留；具名標籤已移除時退回全部追蹤，記憶與改名模式納入設定匯出及分類還原。

## 新手與快速入口

- 資訊頁「使用指南」或 F1 開啟 17 章新手指南，包含可記憶的六項學習清單、搜尋、列印及前往操作。清單只記錄進度，不會自動操作資料；儲存受限時會提示。
- 資訊頁「找功能」或 Ctrl+K 可搜尋既有功能入口。搜尋後 Enter 開啟第一項，方向鍵可移動焦點；空白查詢按 Enter 不會自動導航，其他對話框開啟或忙碌時不啟動。
- [離線新手指南](user-guide-zh-Hant.html) 與 app 內內容共用來源；執行 `npm run guide` 重新產生單檔 HTML。
- 查看紀錄標題、箭頭及空白處在原頁展開／收合詳情；「提醒」與「前往工作區」移到詳情內，保留浮窗釘選編輯，主視窗及浮窗增加頁面留白。

查看紀錄的新介面將常用搜尋、進階條件及檢視分開；可使用快速日期與可移除條件標籤，結果以表格、狀態及標籤提供閱讀線索。詳見 [紀錄瀏覽設計與參考](record-browser-design.md)。

## Everything 操作

### 啟動時選取

1. 「設定 → 我的收藏 → 重新啟動後回到上次使用的收藏分頁」預設開啟，既有安裝升級也會生效。最後選取的檔案、工作區或 Everything 分頁會跨次啟動還原。若要固定初始分頁，取消此開關後再選預設分頁。
2. 同頁可指定 Everything 初始追蹤搜尋。目標已移除時使用第一個追蹤搜尋。
3. 若要啟動應用程式後直接顯示收藏，另在「設定 → 啟動」將啟動頁設為「我的收藏」。

初始搜尋在本次啟動首次載入追蹤時選取；之後切換追蹤時保留本次選擇。

### 搜尋預設與快速條件

一般 Everything 搜尋與追蹤編輯器共用「搜尋預設、快速條件與自訂檔案類型」。

- 提供 12 個預設：最近 7 天、今天、本月、大型影片、超過 1 GB、最近文件、PDF、圖片、壓縮檔、程式碼、空檔案、資料夾。「套用預設」會取代搜尋條件與內建類型。
- 快速條件以 AND 加入；原式使用 OR 時會保留分組。例如 `ext:pdf | ext:docx` 加入最近 7 天，變成 `<ext:pdf | ext:docx> dm:7days`。
- 保留原有日期／大小與副檔名快速條件，另可快速加入只有檔案／資料夾、唯讀、隱藏、排除系統檔、壓縮／加密屬性、排除暫存副檔名與程式相依資料夾。
- 檔名／路徑條件選單可輸入包含、排除、完整檔名、開頭、結尾、區分大小寫、完整單字、萬用字元、regex 或路徑文字。文字會加引號；不接受雙引號／控制字元。正則表達式由 Everything 解讀。
- 可輸入完整 Windows 資料夾路徑後按「限定資料夾」、「排除此資料夾」或「只搜尋直接子項目」；含空格路徑會加引號。
- 可繼續手動編輯 Everything 原生條件。實際搜尋由本機 Everything 版本解讀。

欄位及固定匯出參數參考：[官方 ES 命令列工具](https://github.com/voidtools/ES)。每次查詢用 `-columns` 明確取代 ES 從 `es.ini` 載入的欄位配置，確保 CSV 順序與欄數固定，不寫入 ES 個人設定。舊 ES 不支援額外欄位參數時會自動回退原路徑查詢，相關額外資訊顯示 —。

官方語法參考：[Everything 搜尋說明](https://www.voidtools.com/support/everything/searching/)、[搜尋函式](https://www.voidtools.com/support/everything/search_functions/)。內建類型使用明確 `ext:` 清單，以相容 IPC 搜尋。

### 類型與自訂清單

新增 PDF、試算表、簡報、文字／設定、程式碼、電子書、資料庫、字型、磁碟映像、字幕、設計／CAD／3D，共 17 個內建副檔名分類，另有檔案／資料夾選項。

選「自訂副檔名」，輸入例如 `.pdf, docx, xlsx`。可為清單命名後儲存，兩個搜尋介面共用已存清單。最多 30 組，每組最多 100 個副檔名；分隔接受逗號、分號、空格，會去重、忽略大小寫。副檔名不接受搜尋運算子、萬用字元或完整路徑。

每個追蹤儲存當時的副檔名清單。更新或移除具名類型後，原有追蹤保留自己的清單；重新「使用此類型」再儲存追蹤才會變更。

### 複製、選取、寬度與右鍵

- 標題列「複製搜尋條件」會包含類型篩選。可貼回 Everything，例如 `file: ext:docx;pdf <dm:7days>`；只有檔案／資料夾也會帶上限制。
- 每列右側按鈕直接複製該項目的完整路徑；不需要先勾選。批次複製仍使用工具列。
- 單擊選取、Ctrl 點擊增減、Shift 範圍選取；雙擊名稱開啟項目，雙擊位置開啟所在位置。
- 拖曳左側面板分隔線或欄位標題右緣可調整寬度並儲存。分隔線可用左右鍵微調，Home／End 到邊界；雙擊欄位分隔線自動調整適合內容，工具列可還原全部寬度。
- 右鍵結果列提供開啟、所在位置、三種複製、F2 改名、批次改名／搬移、保留收藏、選取及編輯搜尋；點未選列會改選該列，點已選列會保留多選。Shift+F10 可開啟已選列選單。
- 「選擇欄位」或右鍵標題可顯示／隱藏欄位，預設維持檔案名稱、所在位置、大小與修改日期。名稱固定顯示，其餘可選擇並記住，亦可還原預設四欄。
- 額外十欄為副檔名、類型（依副檔名顯示）、建立日期、存取日期、屬性、最近更改日期、執行次數、執行日期、檔案清單檔案名稱與完整路徑。日期與屬性等資訊由 Everything 索引提供；未索引／未提供時顯示 —。執行次數與日期是 Everything 自己的開啟紀錄，本程式不增加該計數；存取日期也不一定即時更新。
- 右鍵標題可指定遞增／遞減排序、調整適合單欄／所有欄位大小及還原欄寬。每個追蹤搜尋記住目前排序欄位與方向，各欄位也保留上次方向，更新、重啟與切換追蹤後還原。暫時隱藏排序欄位時改用名稱排序，重新顯示後還原原排序。排序使用原結果識別，後續操作仍會核對所選檔案。
- 「收合操作工具」可收起定時更新、選取、批次操作及快捷鍵說明，重新啟動也記住狀態；收合列顯示更新間隔或暫停原因。已選數量與「所選項目操作」保留在外，右鍵與快捷鍵持續可用；收合不清除選取或重新查詢。
- 「暫停追蹤／恢復追蹤」直接切換目前搜尋的啟用狀態，儲存於既有追蹤資料；恢復目前可見搜尋時立即更新。
- 「複製所選表格」可由批次工具列、右鍵或「所選項目操作」使用，依畫面排序及可見欄位複製含欄名的 Tab 分隔文字，貼到試算表即可分欄；控制字元轉空白，公式前綴加單引號。仍會核對快取版本與檔案身分，內容上限 2 MB。
- 追蹤結果只在記憶體保留；定時更新只處理目前顯示的搜尋，選取結果或開啟對話框時暫停自動更新。

### 浮動快捷

「設定 → 浮動工具 → 編輯快捷動作」選 Everything 追蹤，指定搜尋及動作：

| 動作 | 指定搜尋 | 行為 |
| --- | --- | --- |
| 開啟追蹤結果 | 選填 | 開主視窗收藏的 Everything 分頁，可指定一個搜尋。 |
| 複製完整搜尋式 | 必填 | 複製搜尋文字與檔案類型限制。 |
| 立即更新 | 必填 | 呼叫本機索引更新該搜尋，顯示成功筆數或失敗原因。 |
| 追蹤選單 | 選填 | 列出指定／全部搜尋，每項可開啟、複製或更新。 |

可套用既有按鈕圖示、顯示方式、啟用開關、排序及全域快捷鍵。搜尋移除、暫停或按鈕變更後，執行時會重新核對。

## 驗證範圍

自動測試涵蓋：新類型與副檔名驗證、OR 分組、搜尋預設、路徑引號、具名類型跨編輯器使用、備份驗證、初始分頁與搜尋、欄位選擇與寬度保存／還原、索引 CSV 格式與舊 ES 回退、排序後快速複製與選單、多選保留、主視窗 IPC 限制、浮動按鈕／快捷鍵及首頁導覽。

Windows Everything 實際索引、原生視窗尺寸、滑鼠拖曳觀感及安裝包仍需 Windows 實機驗證。

浮動查看紀錄採搜尋／表格選單及標題／日期並排，保留標題與空白處展開；主頁標題精簡，日曆／看板新增主題底色層次。

Everything 追蹤名稱欄載入系統圖示；Delete、工具列及右鍵選單支援確認後回收所選檔案／資料夾，合併父子重複來源，核對來源及子項目，成功後移除相關一般收藏並更新追蹤。資料夾內所有內容會一併回收，每批最多 5000 個項目（含子項目）；無法回收時顯示失敗，不改為永久刪除。工作區文字路徑保留，還原檔案請至 Windows 資源回收筒。

「篩選目前結果」只在目前最多 500 項內比對檔名／完整路徑，空格分隔的詞全部符合，不改動 Everything 命令且不重新查詢。各追蹤在本次使用期間保留篩選文字；變更條件會清除選取，Ctrl+A、反選及範圍選取只處理顯示結果。工具列收合後篩選仍可使用。資料夾採固定黃色圖示；回收後只移除已回收來源及其子項目，保留其他結果並更新操作憑證，查詢失敗也不會清空剩餘清單。

追蹤結果篩選旁的 ⓘ 提供滑鼠、鍵盤聚焦與點擊提示，Esc 關閉；說明不再固定佔行。複製操作欄預設顯示，可從任一資料欄標題或複製欄右鍵切換，也可在「選擇欄位」勾選；everythingShowCopy 設定跨重啟保留、納入匯出與收藏分類還原，資料排序／表格匯出不包含此操作欄。浮動查看紀錄將表格與主紀錄選單並排，較寬時搜尋同列，表格／檢視與清除篩選合併摘要列。

追蹤頁按 Ctrl+F 聚焦並選取結果篩選，對話框、忙碌或其他頁面不攔截。大小單位以 everythingSizeUnit 保存（auto／bytes／KB／MB／GB），KB／MB／GB 每級 1024；結果與複製表格同步格式化，排序仍讀原始 bytes。設定 → 收藏提供此單位、everythingFileIcons 系統檔案圖示及複製欄的控制，支援設定搜尋、匯出與分類還原。

WindowsFileIcons 透過可重用的背景 PowerShell／Win32 程序讀取 PNG 圖示，不改動來源檔案。捷徑只讀 metadata、指定 iconIndex 與本機目標，從不執行 target 或 args；網路／URI 圖示來源不送至讀取程序。請求採 JSON stdin、並行上限與逾時回退，離開 app 關閉程序。原生檔案圖示及 `.lnk` 的實際 Windows 外觀仍需實機驗證。

## 統一工具箱與情境浮層（v1.127.0）

頂端「工具箱」保留收件匣、情境包、參數範本、追蹤變更、離線 OCR、自動流程及備份七個常用入口。工作集與文字範本管理位於相關工具內，其他功能收在「其他工具」，目的地在操作內。Ctrl+Shift+K 開收件匣，有檔案選取時 Ctrl+K 帶入來源。各工具共用工作區、收藏、整理規則、草稿、提醒及預覽服務。工具列「情境」開啟浮層，可直接切換、預選主紀錄、範本及追蹤，並直接取用常用資源；常駐橫列已移除，不增加工作頁高度；切換不更改搜尋或日曆範圍，未使用情境與選擇都保存到原有 workflow-state.json。
