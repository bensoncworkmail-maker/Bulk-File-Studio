## 快捷標籤與明細計數

「從現有標籤選取」來自目前收藏及有效工作區紀錄，排除紀錄或表格的回收筒標籤；路徑匯入快捷只讀收藏。不分大小寫去重，刪除收藏標籤不會連帶改寫有效工作區紀錄。快捷動作的預設標籤與現有清單分開，設定中的預設值仍會填入，可在設定修改或在本次表單清除。

已開啟表單收到收藏／工作區變動、重新聚焦或連續新增後會更新選項，不重設欄位、手動輸入標籤或勾選位置。使用者已輸入的草稿標籤不會因清單更新而自動刪除；既有位置若在其他視窗移除，儲存時仍由後端要求重選。

明細分頁用獨立 8px 圓角矩形徽章顯示目前主紀錄的有效筆數（包含 0），選中分頁加強外框；讀屏名稱包含筆數，隱藏數量偏好與左右鍵分頁仍生效。

## 儲存與確認

單筆直接儲存會在主程序先驗證，再以受版本檢查的交易新增；沒有跳過關聯或位置檢查。完成後阻止重送；有失敗不關閉視窗。新增位置由原生選擇器授權，預覽與寫入再核對來源身分；其他收藏若被移除或換位置，會停止要求重選。原檔案不會被修改。

連續新增只保留所選欄位／標籤，新選位置與收藏勾選會清空，避免下一筆誤連到上一筆檔案。取消未儲存的表單不加入新選位置；新位置儲存期間若收藏成功但紀錄失敗，會明示收藏已加入，供重新預覽，不宣稱兩份檔案是同一交易。

快捷設定保留舊動作相容；新增表單配置為選用屬性。設定匯出會包含使用者填的預設值，分享前請自行檢查內容。版面預設只改視覺偏好，不改工作區資料、接收授權或提醒排程。可個別還原分類。

設定頁的相容性檢查只讀取選定 JSON 並驗證，不匯入、不建立收藏、不改工作區。無法保證任意損壞或其他軟體的檔案可讀；不支援格式會停止。正式搬移先保留完整資料位置及匯出資料包，重建 EXE 不應刪除使用者資料位置。

## 紀錄提醒

- 每 30 秒檢查，程式完全退出時不執行；留在系統匣屬仍在執行。重新開啟會列出逾期項目。
- 到期狀態先保存才送通知，避免同一筆每 30 秒重複通知；待辦提示保留到完成或延後。每天／每週在完成後安排下一次，錯過多次不連續轟炸。
- 可選系統通知、程式內彈窗、兩者；聚焦另有開關。編輯／快捷表單／檔案操作中暫緩彈窗，資料與輸入不被關掉。可延後 5／10／15／30／60 分鐘。
- 強提醒是選用的第四種方式：獨立、非主視窗 modal 的置頂視窗，內有每筆完成／延後與整窗稍後處理。預設不搶輸入焦點，聚焦沿用既有開關；不要求放棄草稿。快捷表單或檔案操作中延後顯示及重播。主視窗草稿不被關閉，強提醒也不執行工作區匯入或改寫紀錄。
- 強提醒可選系統提示音，只響一次或每 1／5／10／15 分鐘重播（預設 5）。關閉只停止目前這次的強提醒視窗及提示音，不會將排程標成完成；待處理清單仍保留。完成循環排程安排下一次；延後到期可再顯示。關閉程式後不執行，重啟補列仍未處理的強提醒。
- 停用提醒會立即關閉強提醒；回收紀錄、改提醒方式或刪除排程也會重新核對。原生視窗只允許自身主框架讀取到期強提醒、完成／延後／關閉，不能調用主視窗的資料修改或檔案操作 IPC。聲音失敗寫入診斷，不把已成功完成的提醒操作改報失敗。
- 新版保留原有個人提醒格式與通知／彈窗選項；更舊程式不識別強提醒類型時會停止讀寫該提醒檔，避免覆寫。工作區與共享資料格式不受影響。
- 紀錄或所屬表格回收／移除時不送提醒，清單標示不可用；還原後逾期可再提醒。另存副本的新 ID 不會自動複製原紀錄提醒。
- 系統通知可能受 Windows 設定、勿擾模式或安裝捷徑影響；程式內待辦仍保留。提醒不對外傳送紀錄內容，系統通知只顯示到期數。

設定搜尋會先展開目標所在的摺疊區，再捲到並聚焦控制項，避免搜尋到快捷表單設定卻看不到內容。標籤與收藏選擇清單每次只顯示最多 200 項，搜尋涵蓋全部資料，切換搜尋保留已選位置。

本次核對 88 個介面與 71 個桌面設定綁定，沒有缺少控制項或重複 HTML ID。原生視窗由實際螢幕範圍限制，不允許設定把視窗完全移到螢幕外。這些是受控版面配置，未加入任意 HTML/CSS 編輯器或外部程式執行器。

- https://www.electronjs.org/docs/latest/tutorial/notifications
- https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/

強提醒原生 API 參考：https://www.electronjs.org/docs/latest/api/browser-window （showInactive、flashFrame、alwaysOnTop）；https://www.electronjs.org/docs/latest/api/shell （beep）。Windows 實際置頂、工作列與提示音仍須以建置後的 EXE 驗證。

## 回收筒與浮動全域搜尋（v1.49.0）

工作區「更多操作 → 回收筒」保留已回收紀錄及其標籤，沒有獨立標籤回收筒。收藏標籤移除不建立回收項目；實體檔案回收是 Windows 的另一套功能。回收清單有列容器、內距、標籤、時間與表格還原限制說明；還原紀錄保留原標籤，不修改實體檔案。

浮動全域搜尋重用同一個本機搜尋模型，固定來源為有效紀錄、收藏、標籤、已登記位置與表格；不提供舊群組入口，也不索引改名工作台暫存清單、命名範本或 Everything 磁碟索引。每類 25 項，單一類型可翻頁；主從關聯選項預設關閉。原本浮動搜尋框仍維持模式內篩選，點全域按鈕會帶入目前文字。

面板是受限的非 modal 原生子視窗，依螢幕邊界放在浮動工具旁，保持置頂偏好；不因失焦或開啟位置而隱藏浮動工具。主視窗只在明確要求查看時開啟，未儲存編輯由原有導覽保護阻擋。設定可停用面板及設定下次開啟的預設尺寸；浮動工具隱藏或銷毀、程式結束時面板會關閉。

搜尋操作綁定本次結果 token、類型及索引，10 分鐘失效；新搜尋、讀取失敗或本機資料變動立即撤銷舊 token。開檔只接受返回結果中已連結的收藏 ID，核對目前路徑、存在狀態與原有安全開啟規則；原始文字路徑沒有直接開啟權限。面板不能呼叫主視窗修改資料、刪除或匯入 IPC。設定納入搜尋、匯出及浮動分類還原。Windows 原生位置與跨視窗焦點仍須以 EXE 實機驗證。

## 浮動即時搜尋（v1.50.0）

新增 `floatingSearchMode`（local／live，預設 local）、`floatingSearchDelay`（150／300／500／800 毫秒，預設 300）、`floatingSearchMinLength`（1／2／3，預設 1），分類為浮動工具，均可搜尋、匯出與還原。既有全域搜尋總開關及面板寬高沿用；總開關停用時回到原模式內篩選。設定切換只取消舊查詢，不自動送出既有輸入。

即時模式以原浮動搜尋欄為輸入來源。只更新外部結果，不把同一段全域文字再當作工具內收藏／主檔篩選。中文 composition 期間暫停並取消先前的即時查詢，完成選字後再延遲觸發。每次輸入先準備新的要求識別碼、撤銷舊 token，再等延遲；後來的要求、清空、Esc、設定變更會使舊計時器及已排隊要求失效。

原生自動面板以 show:false 建立，ready-to-show 後 showInactive，不主動 focus；既有面板只更新文字與結果，不重開視窗。只有原浮動工具仍可見且有焦點時才接受自動顯示，避免切到其他程式後才彈出。Enter／向下鍵是明確的移入結果操作，不直接執行第一個項目。自動面板隱藏自己的輸入框，關閉已聚焦的面板時將原生焦點返回可見的浮動工具。手動面板沿用完整輸入框及明確聚焦行為。

搜尋 IPC 帶面板版本，過期 query／版本不能撤銷或覆寫較新結果；pending 狀態不接受舊查詢。原有 token、收藏路徑核對、10 分鐘期限及開啟規則保持。Esc／清空只取消自動面板，手動搜尋不被這些被動事件關閉。一般資料變更仍會刷新可見結果；中文選字、不足字數及已取消狀態不會重啟舊查詢。

原生 showInactive 參考：https://www.electronjs.org/docs/latest/api/browser-window#winshowinactive 。Windows 焦點、中文輸入法與置頂互動仍需建置 EXE 後實機驗證。

`globalSearchCriteria` 保存在 desktop-state，透過設定頁的「共用全域搜尋預設」套用，可匯出與全域搜尋分類還原。包含來源、全部／指定表格、修改起迄日，以及筆記／標籤／位置比對開關。主視窗使用已儲存預設；v1.53.0 起浮動面板以此初始化，再傳入面板內的當次條件，主程序重新驗證，並不改寫已儲存設定。浮動視窗不讀取主視窗 localStorage。資料表、日期與來源篩選在分頁與關聯擴展前完成，關聯結果不會超出指定紀錄範圍；所屬主紀錄名稱仍可作為明細脈絡。

## v1.53.0：面板篩選、標籤多選及獨立共享

首頁問題來自設定通知只對 `home...` 欄位重畫，遺漏 `layoutEditing`。現在同一條通知路徑立即更新編輯工具列與區塊控制，不必切頁。

快捷標籤選「勾選多個標籤…」後，勾選要顯示的分類。以選用的 `tagKeys` 保存標籤鍵，原單選 `tag` 保留相容。多選不能是空陣列，標籤消失時顯示不可用，不改成全部。各標籤的原生子選單保留開啟、定位與批次確認；複製多選分類的路徑會依收藏 ID 去重。多個分類可能顯示同一份收藏，這是分類中的同一項，沒有複製實體檔案。

共享管理新增主表選擇。原 `workspace-share.json` 保留，獨立主表設定存在本機 `workspace-share-profiles/<master ID>.json`，不放進共享包或一般設定匯出。每組使用自己的來源 UUID、不可覆寫版本、已接收清單、忽略紀錄、接收基準、路徑、定時器與通知偏好。發布與接收固定限制在該主表與明細；本機資料庫仍是同一份。不同啟用組別不可重疊管理主表，亦不可使用同一資料夾，避免混入其他主表來源。原共用設定若涵蓋全部，先縮小發布與接收範圍或停用，再啟用重疊主表的獨立組別。

獨立組別以範圍內的資料指紋檢查本機修改與自動發布，防止修改 B 紀錄導致 A 重複發布或暫停接收；提交時仍使用當前工作區修訂做交易衝突檢查，編輯／匯入時的閒置保護與備份保留。跨主表必要參照結構仍可能影響相依檢查，但不發布其他主表紀錄。換路徑只清除本組接收信任並停用本組，其他組別不變。重開恢復各組設定與檢查；切換管理組別使現有匯入預覽失效。各組待處理更新會在選擇器標示，也會在其他頁的提示列顯示名稱。共享快捷的檢查／發布使用目前管理組別，發布確認會列出名稱與資料夾。

例如客戶主表用 `H:\Share_Backup\Clients`，專案主表用 `H:\Share_Backup\Projects`。從客戶來源包接收或複製時只套用客戶範圍，專案的有效紀錄、回收筒與結構均由原有範圍匯入保護。接收端須先匯入來源以保留 ID，再選該主表配置獨立共享；相同名稱不會自動配對成同一主表。

## v1.54.0：收合進階條件與日期快捷

浮動搜尋的表格／日期／來源及比對條件由原有常駐區改成原生 `details`，預設收合，可用鍵盤操作。收合摘要顯示表格數、日期及其他限制，長摘要可看完整提示；切換展開不重新搜尋，不清除條件，後續即時查詢亦保留展開狀態。日期快捷列在 `details` 外，搜尋結果繼續使用餘下高度。

設定 → 全域搜尋的新卡管理 `floatingSearchFiltersExpanded` 與 `floatingSearchDatePresets`；前者只決定新面板開啟時的狀態，後者在存檔後同步更新已開啟面板的按鈕，不覆寫其當次日期、文字或展開狀態。所有新偏好可設定匯出及搜尋分類還原；無關設定更新不覆蓋尚未儲存的按鈕草稿。刪到零個或全設為不顯示，快捷列隱藏；不會偷偷恢復預設按鈕。

日期快捷最多 12 個，名稱 1–24 字元。支援不限日期、今天、昨天、含今天最近 N 天（1–3650）、本週／上週、本月／上月、相對今天的起迄日（各 -3650 至 3650）與固定日期。起日不可晚於迄日；重複 ID、錯誤日期及不合法天數會停止儲存，保留原設定與草稿。固定日期不隨今天改變，其他日期在點擊當下以本機日曆計算。週一至週日、月份取完整月份，迄日包含整天；日數使用日曆加減，避免夏令時間造成偏移。

例如 2026-11-03 點「最近 7 天」套用 2026-10-28 至 2026-11-03；自訂「最近 14 天」則為 2026-10-21 至 2026-11-03。快捷只改日期，已勾選的客戶／聯絡人表格及來源不變；「不限日期」也只清除日期。
