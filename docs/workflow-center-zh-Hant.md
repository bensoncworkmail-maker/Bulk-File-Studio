# 工具箱：收集、整理與自動化

v1.125.0 將工作流程中心併入「工具箱」，取消第二個視窗和橫向頁籤。七個常用入口在左側；每頁先看短說明及三步操作，需要細節時再展開選項或「用途、使用情境與操作例子」。既有資料及快捷入口沿用。

## 七個入口，從哪裡開始？

| 入口 | 第一次可以做什麼 | 例子 |
| --- | --- | --- |
| 收件匣 | 輸入標題與內容，直接儲存；附件選填 | 接到電話，先記「客戶 A 星期五前要報價」，稍後才選工作區表格 |
| 情境包 | 設定名稱、主紀錄及資源；之後從頂端直接切換 | 建「客戶 A」，連結該客戶的追蹤搜尋及回覆範本 |
| 參數範本 | 先建立文字範本，再填參數、預覽、複製 | `{{record.title}} 您好，關於 {{subject}}，我們將於 {{today}} 回覆。` |
| 追蹤變更 | 選一個追蹤搜尋，按「立即檢查」建立基準 | 再次檢查「客戶 A 最近 PDF」，核對新增及可能改名項目 |
| 離線 OCR | 選一張圖片，辨識後校正，再存入收件匣 | 收據辨識後逐項核對日期及金額 9,800 |
| 自動流程 | 建一條手動流程，選紀錄，預覽後才執行 | 對未完成跟進建立 60 分鐘後的提醒，試跑確認後才考慮事件觸發 |
| 備份 | 建立完整備份，按「試還原」核對 | 匯入大量 Excel 前留下版本，必要時先預覽再確認還原 |

「進階」不必一開始全部設定。收件匣可純文字；情境包可只放主紀錄；OCR 通常使用系統語言；自動流程預設手動，事件執行須明確啟用。

## 日常直接切換情境

v1.126.0 起，頂端常駐「目前情境」，工具箱的情境包頁用來設定與管理，日常不必返回該頁。

1. 第一次按「建立情境」或到「工具箱 → 情境包」，建立「客戶 A」，連結主紀錄、追蹤及回覆範本。
2. 在任何主頁，從頂端「目前情境」選「客戶 A」。留在目前頁面，主紀錄名稱會顯示在旁邊。
3. 要查看客戶資料，按「開啟主紀錄」；要找報價或回覆，展開「常用資源」，直接開對應追蹤或範本。
4. 在參數範本會預選 A 的主紀錄及第一個有效範本；在追蹤變更會預選 A 的第一個有效追蹤。收件匣轉入明細與彙總沿用 A 的主紀錄，仍可手動改選。
5. 改處理「客戶 B」時，直接在頂端切換。選「未使用情境」清除預選；選擇及清除都跨重啟保存。

切換情境不會導航、建立紀錄、搬移檔案，亦不改變全域搜尋、日曆、看板或工作區目前的篩選。明確點選「儲存檢視」後才套用該檢視。相關工作集仍使用原有開啟前確認。

有未儲存的流程表單會先確認；取消或寫入失敗時，內容及未儲存狀態都保留。只有切換成功後才清除已同意放棄的舊內容；寫入期間暫停目前流程表單輸入。單純查看選項不會觸發放棄提示。正在執行操作或開啟紀錄編輯視窗時先完成或取消。資料已變更時，切換會停止並重新讀取實際情境，避免舊版本覆蓋。

主紀錄或資源已移除時會標示並停用無效入口，可按「管理情境」修正。開啟常用資源後可用 Tab 選操作，Esc 關閉並回到開啟按鈕；點擊面板外也會關閉。

## 既有工具移到哪裡？

| 既有入口 | 新位置 |
| --- | --- |
| 動作面板、選取來源與跟進草稿 | 收件匣；Ctrl+Shift+K 直接開啟，有檔案選取時 Ctrl+K 帶入來源 |
| 工作集管理 | 情境包 → 工作集管理 |
| 常用文字片段管理 | 參數範本 → 文字範本管理 |
| 批次修復路徑、整理規則、文件預覽 | 展開左側「其他工具」 |
| 作業中心、重複檔分析、檔案比較、主表彙總 | 展開左側「其他工具」 |
| AND／OR 條件與衝突 | 其他工具 → 檔案整理規則 → 條件與衝突 |
| 最近／收藏目的地 | 作業中心的輸出目的地；各匯出操作沿用最近位置 |
| 日曆／看板、查看紀錄 | 保留原有頂端入口，不在工具箱重複列出 |

資訊頁「找功能」仍能搜尋所有入口。[完整情境與例子](workflow-examples-zh-Hant.md)。

## 從檔案建立跟進

1. 在 Everything 選取檔案，右鍵選「加入工具箱收件匣…」，或按 Ctrl+K。
2. 收件匣已帶入來源；展開「附加檔案（選填）」可核對、預覽或加入其他來源。
3. 輸入標題與內容，或先從剪貼簿填入並修改。
4. 儲存到收件匣；在草稿展開「整理到工作區」，選轉入表格。只有明細表才顯示所屬主紀錄，選項限於對應主表。
5. 按「建立紀錄並移出草稿」。轉入成功後可前往紀錄；重複送出同一草稿會回傳原紀錄。

草稿與來源標籤分開保存。移除來源標籤不會刪除草稿或檔案；既有草稿視窗仍可編輯。結構化待辦／流程／時間軸轉入時會保留格式化內容。每份草稿最多 48 個來源附件，最多 50 份草稿。

## 搬移佇列與復原

在作業中心選來源及目的地，按「加入搬移佇列」。加入不會立即搬移；按「執行待處理佇列」並核對路徑後才執行。佇列跨重啟保存，啟動時不會自行執行。每批重新核對檔案身分、內容及目的地，拒絕覆寫。

搬移執行在 worker 中進行。可要求安全取消，或於目前批次完成後暫停佇列。取消在來源刪除前的檢查點生效；開始套用來源刪除後會完成或回復整批，不會強行中止於半套用狀態。大檔案的單次複製／校驗中，取消須等待安全檢查點。

作業中心保留最近最多 100 批作業、總日誌上限 24 MiB。復原必須由最新已完成作業開始，完成一批後才能復原前一批；來源被外部修改／取代時會停止。中斷作業會標示待核對，不自動重播。這些歷程保留於本機，不隨可攜備份搬到另一台電腦。原有搬移預覽的規劃階段仍沿用既有服務。

## 情境包與彙總

情境包以主紀錄連結既有工作集、追蹤搜尋、儲存檢視及文字範本。頂端目前情境會跨重啟保留，工具箱以此主紀錄預選收件匣轉入、文字範本與彙總，並預選第一個有效的相關範本或追蹤。檔案不會複製；失效資源可透過編輯重新選擇或移除。

主表彙總可選來源明細表、指向主表的關聯欄位、計算欄位及條件。支援筆數、合計、最小／最大數值、最早／最遲日期，以及距最早日期天數。相同表格可計算目前紀錄本身，無須關聯欄位。畫面收到資料異動會重新計算；計算結果不改寫原始欄位，也不執行任意程式碼。

## 參數化範本

在「工具箱 → 參數範本 → 文字範本管理」建立範本，再回「參數範本」填寫參數。沒有範本時，畫面會提供建立入口及例子。

| 寫法 | 來源 |
| --- | --- |
| `{{customer}}`、`{{subject}}` 等英文參數 | 自動產生的輸入表單 |
| `{{today}}`、`{{time}}`、`{{year}}`、`{{month}}`、`{{day}}` | 本機日期時間 |
| `{{clipboard}}` | 目前剪貼簿文字 |
| `{{record.title}}`、`{{record.notes}}` | 所選紀錄 |
| `{{field.欄位UUID}}` | 所選紀錄欄位；畫面會列出可用的參數寫法 |

缺少參數會停止產生，避免複製未完成文字。「複製內容」在預覽成功後才可用；修改參數或所選紀錄會清除舊預覽。引用紀錄的範本會標示必填紀錄，未選前無法預覽。Windows 可明確選擇「複製並貼到前一視窗」，主視窗會暫時隱藏，並沿用既有目標視窗／焦點檢查。貼上失敗時文字仍在剪貼簿，可手動貼上。

## 規則與自動流程

整理規則可用巢狀 AND／OR 群組。預覽顯示每一條件的實際值與符合結果，並列出多個目的地衝突；真正套用仍沿用工具箱既有預覽、選取與確認流程。每棵條件樹最多 100 個節點、每組 20 項，最多四層。條件樹優先於舊簡單條件；舊表單會明示此狀態，需按「改用下方簡單條件」才切回。

本機自動流程只接受紀錄新增／更新及手動觸發。展開已儲存流程的「手動試跑」，明確選取紀錄才可預覽，核對符合項目與動作後再執行。改動紀錄選取會清除舊預覽。建立時只顯示所選動作的欄位，數字、日期、勾選及單選值採用相應控制項。可設定文字、數字、日期、勾選或單選欄位，或建立草稿／提醒。事件觸發預設關閉；匯入、共享接收及備份還原只更新基準，不觸發流程。啟用後僅執行一層，不會因動作再觸發其他流程。每類設定最多 100 項，保留最近 200 次執行歷程。

## 追蹤變更、重複檔與比較

追蹤變更先建立基準，再比較相同條件的結果；條件改變時重建基準。依檔案身分顯示可能改名，亦列新增、移出結果及屬性變更。這是搜尋結果的差異，不能證明移出結果的檔案已刪除。截斷或略過部分項目時會標示範圍限制。每項最多保留最近 20 次差異；未讀可手動清除。背景檢查預設關閉、最多 20 個搜尋、每分鐘序列執行；不會取消前景 ES 查詢，程式關閉後停止。

重複檔先依檔案大小分組，再計算 SHA-256。沒有預選回收項目；每組至少保留一份內容相同的副本。確認前後會核對所選檔案及保留副本，系統無法回收時回報失敗，不改用永久刪除。單次最多掃描 5,000 個檔案、巡覽 10,000 個項目及 30 層資料夾，不追蹤符號連結。

比較選兩個文字檔或兩個資料夾。文字採 UTF-8／UTF-16，每檔最多 2 MiB、2,000 行；資料夾依相對名稱、大小及內容雜湊比較。兩者均為唯讀，不會啟動工作區共享三方合併。

## OCR、備份及目的地

離線 OCR 需要 Windows 10／11 及已安裝的 OCR 語言。選一張 PNG／JPG／BMP／GIF／WebP（最多 25 MiB），留空語言以使用系統語言，或填入語言代碼。可先預覽原圖；辨識後核對文字，再連同圖片來源存入收件匣。不會上傳圖片。原生辨識與貼上仍需 Windows 實機驗收。

完整備份一律包含草稿、收件匣收據及工作流程設定；可選紀錄歷史與紀錄文件。草稿檔案會嘗試封裝；未封裝的資料夾／文件保留連結並列出原因。附件限單檔 8 MiB、合計 24 MiB、128 個，完整備份最多 48 MiB。備份不包含原始資料夾內容、共享授權、系統登記、追蹤快照及檔案操作歷程。

「試還原」在獨立暫存資料庫載入並比對工作區、草稿、歷史及轉入收據，然後清理暫存，不變更目前資料。正常還原前仍會建立自動備份。

目的地可從最近 12 個資料夾、收藏資料夾或原生瀏覽選擇。應用程式自有設定／資料／Excel／診斷／CSV／完整備份匯出會以最近位置開始。此功能不接管第三方 Windows 開啟／儲存對話框。
