# 工具箱與獨立桌面工作情境

v1.130.0 暫停工作情境與浮動工具合併；移除主表彙總、重複檔分析、檔案比較、自動流程及收件匣。原有草稿、紀錄、提醒及備份保留；舊自動流程沒有執行入口，也不再由紀錄事件觸發。既有設定與轉入收據保留為相容資料，不做破壞性清除。

## 現行入口

| 工具 | 操作與例子 |
| --- | --- |
| 情境包 | 建立「客戶 A」，連結主紀錄、追蹤搜尋、儲存檢視、範本及工作集 |
| 參數範本 | 選紀錄並填參數，先預覽再複製；改參數後重新預覽 |
| 追蹤變更 | 選搜尋，檢查新增／移除／可能改名項目，核對後標示已讀 |
| 離線 OCR | 選一張圖片、辨識並校正，直接存到原有「草稿筆記」；可開草稿再建立正式紀錄 |
| 備份 | 檢查涵蓋範圍，建立備份並試還原；真正還原須核對預覽 |

其他工具：批次修復路徑、檔案整理規則、文件預覽。情境包內可管理工作集，參數範本內可管理文字範本；整理規則仍可設定 AND／OR 條件與查看衝突。v1.131.0 移除作業中心，保留一般改名、搬移、取消及上一批復原。

Ctrl+K 回復統一「找功能」，不再把檔案送到收件匣。原收件匣的 Ctrl+Shift+K 入口已移除。一般草稿仍可透過原有草稿筆記入口及既有快捷鍵操作。

## 日常直接切換情境

1. 在工具箱「情境包」建立客戶或專案，連結常用資源。
2. 從頂端「情境」、浮動工具「▦」或系統匣「桌面工作情境」叫出工作情境；「設定 → 浮動工具 → 工作情境顯示方式」可選程式內面板或**獨立桌面視窗**；不需要返回管理頁。它與浮動工具可同時顯示，不共用視窗、位置或置頂。
3. 從桌面切換客戶，查看主紀錄或儲存檢視、開啟追蹤檔案／工作集，以及填參數、預覽並複製範本。只有明確按「管理情境」才返回主程式。
4. 「顯示選項」可設圖示大小 **24–64px 整數**（預設 **32px**）。按「桌面圖示」收合；拖曳邊緣移動。懸停約 280ms 展開，不搶鍵盤焦點；移開約 500ms 收合，有焦點、未完成參數或處理中操作時保持展開。
5. 「面板模式」或「保持展開」可常駐；置頂獨立設定。位置、尺寸與目前情境跨重啟保留。「×」隱藏，原入口可叫回。

主程式未儲存或忙碌時，桌面切換會停止並保留原情境；桌面參數未完成時也阻止主程式同時切換。切換只預選參數範本及追蹤資料，不改搜尋或日曆範圍。失效資源停用，可在管理頁修正。
