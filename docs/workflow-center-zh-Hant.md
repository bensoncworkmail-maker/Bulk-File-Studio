# 工作流程中心

v1.123.0 起，頂端「工作流程」或 Ctrl+Shift+K 可開啟中心。Everything／一般收藏已有選取檔案時，Ctrl+K 優先帶入動作面板；沒有檔案選取時仍開啟找功能。資訊頁「找功能」按鈕永遠保留功能搜尋。

## 從檔案建立跟進

1. 在 Everything 選取檔案，右鍵選「工作流程／建立跟進草稿」，或按 Ctrl+K。
2. 動作面板已帶入來源；也可在中心選檔案、資料夾或使用目前收藏選取。
3. 選「建立跟進草稿」，輸入標題與內容，或先從剪貼簿填入並修改。
4. 儲存到收件匣；選擇轉入表格。明細表需選擇所屬主紀錄。
5. 轉入成功後可直接前往紀錄；重複送出同一草稿會回傳原紀錄。

草稿與來源標籤分開保存。移除來源標籤不會刪除草稿或檔案；既有草稿視窗仍可編輯。結構化待辦／流程／時間軸轉入時會保留格式化內容。每份草稿最多 48 個來源附件，最多 50 份草稿。

## 搬移佇列與復原

在作業中心選來源及目的地，按「加入搬移佇列」。加入不會立即搬移；按「執行待處理佇列」並核對路徑後才執行。佇列跨重啟保存，啟動時不會自行執行。每批重新核對檔案身分、內容及目的地，拒絕覆寫。

搬移執行在 worker 中進行。可要求安全取消，或於目前批次完成後暫停佇列。取消在來源刪除前的檢查點生效；開始套用來源刪除後會完成或回復整批，不會強行中止於半套用狀態。大檔案的單次複製／校驗中，取消須等待安全檢查點。

中心保留最近最多 100 批作業、總日誌上限 24 MiB。復原必須由最新已完成作業開始，完成一批後才能復原前一批；來源被外部修改／取代時會停止。中斷作業會標示待核對，不自動重播。這些歷程保留於本機，不隨可攜備份搬到另一台電腦。原有搬移預覽的規劃階段仍沿用既有服務。

## 情境包與彙總

情境包以主紀錄連結既有工作集、追蹤搜尋、儲存檢視及文字範本。啟用的情境會跨重啟保留，中心以此主紀錄預填收件匣及文字範本。檔案不會複製；失效資源可透過編輯重新選擇或移除。

主表彙總可選來源明細表、指向主表的關聯欄位、計算欄位及條件。支援筆數、合計、最小／最大數值、最早／最遲日期，以及距最早日期天數。相同表格可計算目前紀錄本身，無須關聯欄位。畫面收到資料異動會重新計算；計算結果不改寫原始欄位，也不執行任意程式碼。

## 參數化範本

先在工具箱「常用文字片段」管理範本，再到中心「參數範本」填寫缺少的參數。

| 寫法 | 來源 |
| --- | --- |
| `{{customer}}`、`{{subject}}` 等英文參數 | 自動產生的輸入表單 |
| `{{today}}`、`{{time}}`、`{{year}}`、`{{month}}`、`{{day}}` | 本機日期時間 |
| `{{clipboard}}` | 目前剪貼簿文字 |
| `{{record.title}}`、`{{record.notes}}` | 所選紀錄 |
| `{{field.欄位UUID}}` | 所選紀錄欄位；畫面會列出可用的參數寫法 |

缺少參數會停止產生，避免複製未完成文字。先預覽再複製；Windows 可明確選擇「複製並貼到前一視窗」，主視窗會暫時隱藏，並沿用既有目標視窗／焦點檢查。貼上失敗時文字仍在剪貼簿，可手動貼上。

## 規則與自動流程

整理規則可用巢狀 AND／OR 群組。預覽顯示每一條件的實際值與符合結果，並列出多個目的地衝突；真正套用仍沿用工具箱既有預覽、選取與確認流程。每棵條件樹最多 100 個節點、每組 20 項，最多四層。條件樹優先於舊簡單條件；舊表單會明示此狀態，需按「改用下方簡單條件」才切回。

本機自動流程只接受紀錄新增／更新及手動觸發。先選紀錄試跑，核對符合項目與動作，再執行。可設定文字、數字、日期、勾選或單選欄位，或建立草稿／提醒。事件觸發預設關閉；匯入、共享接收及備份還原只更新基準，不觸發流程。啟用後僅執行一層，不會因動作再觸發其他流程。每類設定最多 100 項，保留最近 200 次執行歷程。

## 追蹤變更、重複檔與比較

追蹤變更先建立基準，再比較相同條件的結果；條件改變時重建基準。依檔案身分顯示可能改名，亦列新增、移出結果及屬性變更。這是搜尋結果的差異，不能證明移出結果的檔案已刪除。截斷或略過部分項目時會標示範圍限制。每項最多保留最近 20 次差異；未讀可手動清除。背景檢查預設關閉、最多 20 個搜尋、每分鐘序列執行；不會取消前景 ES 查詢，程式關閉後停止。

重複檔先依檔案大小分組，再計算 SHA-256。沒有預選回收項目；每組至少保留一份內容相同的副本。確認前後會核對所選檔案及保留副本，系統無法回收時回報失敗，不改用永久刪除。單次最多掃描 5,000 個檔案、巡覽 10,000 個項目及 30 層資料夾，不追蹤符號連結。

比較選兩個文字檔或兩個資料夾。文字採 UTF-8／UTF-16，每檔最多 2 MiB、2,000 行；資料夾依相對名稱、大小及內容雜湊比較。兩者均為唯讀，不會啟動工作區共享三方合併。

## OCR、備份及目的地

離線 OCR 需要 Windows 10／11 及已安裝的 OCR 語言。選一張 PNG／JPG／BMP／GIF／WebP（最多 25 MiB），留空語言以使用系統語言，或填入語言代碼。可先預覽原圖；辨識後核對文字，再連同圖片來源存入收件匣。不會上傳圖片。原生辨識與貼上仍需 Windows 實機驗收。

完整備份一律包含草稿、收件匣收據及工作流程設定；可選紀錄歷史與紀錄文件。草稿檔案會嘗試封裝；未封裝的資料夾／文件保留連結並列出原因。附件限單檔 8 MiB、合計 24 MiB、128 個，完整備份最多 48 MiB。備份不包含原始資料夾內容、共享授權、系統登記、追蹤快照及檔案操作歷程。

「試還原」在獨立暫存資料庫載入並比對工作區、草稿、歷史及轉入收據，然後清理暫存，不變更目前資料。正常還原前仍會建立自動備份。

目的地可從最近 12 個資料夾、收藏資料夾或原生瀏覽選擇。應用程式自有設定／資料／Excel／診斷／CSV／完整備份匯出會以最近位置開始。此功能不接管第三方 Windows 開啟／儲存對話框。
