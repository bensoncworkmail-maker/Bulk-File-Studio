# 工具箱

## 現行入口

| 工具 | 操作與例子 |
| --- | --- |
| 工作集 | 建立「客戶 A 報價」，加入報價資料夾、收藏及工作區紀錄，再從清單一次開啟 |
| 參數範本 | 選紀錄並填參數，先預覽再複製；改參數後重新預覽 |
| 追蹤變更 | 選搜尋，檢查新增／移除／可能改名項目，核對後標示已讀 |
| 離線 OCR | 選一張圖片、辨識並校正，直接存到原有「草稿筆記」；可開草稿再建立正式紀錄 |
| 備份 | 檢查涵蓋範圍，建立備份並試還原；真正還原須核對預覽 |

其他工具：批次修復路徑、檔案整理規則、文件預覽。參數範本內可管理文字範本。整理規則仍可設定 AND／OR 條件與查看衝突。v1.131.0 移除作業中心，保留一般改名、搬移、取消及上一批復原。

Ctrl+K 回復統一「找功能」，不再把檔案送到收件匣。原收件匣的 Ctrl+Shift+K 入口已移除。一般草稿仍可透過原有草稿筆記入口及既有快捷鍵操作。

## 使用工作集

1. 開啟「工具箱 → 工作集」，按「新增」，輸入名稱。
2. 用「選擇檔案」或「選擇資料夾」加入位置，也可拖放或逐行貼入完整路徑。需要時勾選收藏和工作區紀錄。
3. 儲存後從清單選取工作集，按「開啟工作集」並確認。常用工作集也可用浮動快捷動作的外部選單開啟。

既有情境包資料保留供舊版資料相容讀取與備份。工作集仍存於原有工具資料，可直接從新入口開啟。
