# 草稿、快捷鍵、批次工作與備份

v1.78.0 將常用工具改為清單與詳情版面，並補上快捷鍵、獨立草稿提醒、批次資料操作與定時備份。

## 快捷鍵與浮動工具

| 功能 | 設定位置 | 預設 |
| --- | --- | --- |
| 開啟草稿 | 設定 → 草稿筆記 | Ctrl+Alt+D（既有設定保留） |
| 分類文字片段面板 | 設定 → 浮動工具 → 面板快捷鍵 | 未設定 |
| 小月曆 | 設定 → 浮動工具 → 面板快捷鍵 | 未設定 |
| 個別浮動快捷動作 | 設定 → 浮動工具 → 編輯快捷動作 | 未設定 |
| 直接複製個別文字片段 | 工具箱 → 常用文字片段 → 詳情 | 未設定 |

點選快捷鍵欄位後直接按組合鍵，Backspace 清除。程式執行期間才會註冊；相同快捷鍵會被拒絕，若被其他程式占用則保留原設定。文字片段快捷複製會展開今天日期，`{{customer}}` 稱呼變數以空白代入；需要稱呼時請使用片段面板。

浮動快捷按鈕可選「文字」、「僅圖示」、「圖示與文字」，並從內建圖示中選擇。僅圖示仍保留名稱提示與無障礙標籤。已置頂的浮動工具執行快捷動作後會保留；程式在顯示、取得／失去焦點及週期檢查時重套置頂層級，不會搶走其他程式的鍵盤焦點。手動隱藏或切換置頂仍有效。

小月曆可切換月曆、行程清單與看板，點日期後在同窗顯示當日項目。分類文字面板按分類分組，點項目複製。

## 草稿筆記

文字在停止輸入後自動儲存；Esc 先儲存再關閉。內層預覽或另存對話框開啟時，Esc 先關閉該對話框。清單寬度、文字編輯區高度可以拖曳，視窗位置及尺寸沿用原有記憶設定。

| 面板快捷鍵 | 動作 |
| --- | --- |
| Ctrl+N | 新草稿 |
| Ctrl+S | 立即儲存 |
| Ctrl+Shift+S | 另存檔案 |
| Alt+R | 展開並移至獨立提醒時間 |
| Delete | 草稿清單取得焦點時，確認刪除目前草稿 |
| Esc | 儲存並關閉；優先處理內層對話框 |

可在「設定 → 草稿筆記」停用面板快捷鍵或獨立提醒。Delete 不會攔截文字輸入區的刪字操作。

「提醒排程」可直接建立一次、每日或每週提醒，不必建立工作區紀錄。提醒保存當時標題及前 4,000 字內容，送出或刪除原草稿後仍保留，可在主視窗「提醒排程」編輯時間、延後、完成或移除。提醒會出現在日曆。

「另存檔案」預設 `.txt`，可選 `.md`、`.log`、`.csv`、`.json`、`.html` 或自訂副檔名。內容固定為 UTF-8 純文字；更改副檔名不會產生 Word、PDF 等二進位格式，也不會自動把筆記轉成 JSON／CSV 資料。原草稿及附件連結會保留。

草稿字數上限預設 100,000，可在設定調整，`0` 表示不設應用程式字數上限。實際仍受記憶體、IPC 與 SQLite 限制，並非無限容量。降低上限不會截斷既有草稿。工作區筆記仍有 100,000 字限制，超長草稿請先另存檔案。

## 文件與資料夾預覽

「設定 → 草稿筆記」及「設定 → 資料工作區」分別提供預覽方式：

| 方式 | 行為 |
| --- | --- |
| 視窗內預覽 | 文字／圖片在面板中顯示；PDF 使用獨立預覽視窗 |
| 獨立預覽視窗 | 文字、圖片、PDF、資料夾清單另開視窗 |
| 系統預設程式 | 交由 Windows 對應程式或檔案總管開啟 |

文字／HTML 僅顯示文字，不執行內容中的腳本。預覽支援 UTF-8／UTF-16 文字、常用圖片及 PDF；文字最多 2 MB，圖片與 PDF 最多 25 MB。資料夾列出第一層前 200 項，不遞迴掃描。內網位置仍須可連線且有存取權限。

## 情境工作集、文字片段與整理規則

三個工具採左側清單、右側詳情；拖曳分隔線調整寬度，各自記憶。分隔線也支援方向鍵、Home、End。窄視窗改為上下排列。

- **工作集**：直接輸入每行一個位置，或將檔案／資料夾拖到路徑欄，不需先加入收藏。直接路徑與收藏合計最多 20 個位置，另外最多 100 筆工作區紀錄。開啟前核對並確認；無法使用的路徑會列出，不會阻止其他可用項目。
- **文字片段**：按分類瀏覽，可勾選多項後套用分類或刪除；留空分類表示未分類。全選只作用於目前搜尋結果。刪除前顯示確認。
- **整理規則**：目標資料夾支援拖放；也可把檔案／資料夾拖到「產生建議」按鈕，資料夾只檢查第一層，最多 1,000 個檔案。仍須先檢查預覽，再交給原有標籤、改名或搬移流程，不會因拖入就改動檔案。

## 工作區批次操作

新增紀錄的「建立份數」可填 1–500。內容相同，但各紀錄取得獨立 UUID，維持正常的主從關聯與共享識別。

勾選同一表格的 1–500 筆紀錄，按「批次編輯欄位」選擇欄位及新值。支援標題、筆記、分類標籤與自訂欄位；只改選定欄位。先預覽實際差異（顯示前 50 筆），再確認寫入並建立更新前備份。預覽後任何工作區變更都會使舊預覽失效，避免覆蓋他人的新修改。主紀錄關聯必須維持有效；失敗時整批不寫入。

## 日曆與首頁

「設定 → 日曆與紀錄」可設定日期格數量、每週起始日、格子最小高度、字級、每格行程預覽數，以及是否顯示右側日期明細。預覽數 `0` 只保留日期及可選數量。隱藏右側明細時，點日期改用對話框顯示當日項目。

首頁增加今日日期與草稿、日曆、提醒、常用文字入口，原有區塊排序、尺寸及自訂首頁設定保留。

## 完整備份／還原中心

備份位置為目前使用者的程式資料目錄下 `profile-backups`，實際完整路徑顯示於「工具箱 → 備份／還原」，可按「開啟備份資料夾」。不同安裝或可攜位置可能使用不同資料目錄，請以畫面顯示為準。

「設定 → 資料與備份」可停用排程，或設定每 1、6、12、24、168 小時備份。程式執行時每分鐘檢查；關閉程式時不執行，錯過的間隔在下次啟動補做一份，不會逐次補做。備份失敗會顯示訊息，下次檢查重試；不會自動刪除舊備份。

可勾選多份備份後匯出到指定本機資料夾，或確認後永久刪除所選備份。批次匯出遇到同名檔案會跳過並報告，不覆蓋既有副本。還原流程保留原有預覽及還原前自動備份。

完整備份包含工作區、收藏、提醒、工具及設定；原始檔案、尚未送出的草稿及貼上的圖片檔案須另外另存或備份。還原獨立草稿提醒會帶回建立提醒時保存的文字。
