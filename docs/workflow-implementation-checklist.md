## 驗證範圍

- 最終驗證結果見 PR；本清單按實際測試範圍描述，不將原生驗收當成已通過。
- `npm test`：模型、服務、SQLite／JSON 交易、真實 Node worker、主視窗 IPC、操作身分保護及 DOM 互動。
- `npm run check:app`：所有本機資源、入口、設定／DOM 合約與指南版本。
- `tests/workflow.test.js`、`tests/workflow-ui.test.js`、`tests/main.test.js`、`tests/app-help.test.js` 為本輪主要驗收來源；既有全部測試一併回歸。
- worker 驗收模擬 `app.asar`／`app.asar.unpacked` 路徑並按打包宣告複製依賴，執行真實比較與搬移；這不等同完成 Windows EXE 建置。
- 本環境缺少專案本機 Electron／electron-builder，不能啟動完整桌面程式或產生 Windows EXE。現有測試使用執行環境提供的 JSZip／XML 相依套件；未修改生產相依版本。
- Windows 實機仍需驗證：Everything ES 整合與索引更新、OCR 語言／WinRT、前一視窗貼上、資源回收筒、跨磁碟實際檔案系統及安裝包。相關項目未記為實機通過。
- 背景追蹤是程式執行期間的每分鐘檢查；不安裝背景系統服務。第三方程式的開啟／儲存對話框快捷切換仍屬報告提及的後續選配範圍。

## v1.125.0 工具箱整合驗收

- 七個主要入口順序固定；舊工作集、片段、備份等快捷入口仍能到達對應工具。
- 使用實際工具箱與流程 UI 同時載入，測試首次非同步啟動帶入來源、重選保留表單、取消離開保留內容，以及管理子頁切換。
- 參數引用紀錄時必須先選紀錄；預覽前不能複製，修改後清除舊預覽。
- 自動流程依動作顯示欄位、預設不啟用事件；明確選紀錄才可預覽，重新選取會清除舊試跑結果。
- OCR 使用單選圖片對話框，辨識後由使用者校正及明確存入草稿。

Windows 實際縮放、鍵盤操作、OCR／貼上原生行為與安裝包仍需實機驗收；自動化 DOM 驗收不能取代視覺驗收。

## v1.126.0 頂端情境驗收

- 啟動讀取已保存情境，從任意主頁切換或清除；目前主紀錄名稱與作用範圍持續可見。
- 相關資源直接開主紀錄、工作集、追蹤、檢視及指定範本；同一範本頁也能改選資源，不須回管理頁。
- 實際工具箱、流程 UI 與頂端控制器整合測試：切換後預選主紀錄／範本／追蹤；隱藏頁重開採用新情境；搜尋及日曆條件保留。
- 取消未儲存內容的確認不寫入情境；寫入時序列化及鎖住導覽，版本衝突重新讀取，選擇及清除可重啟讀回。
- 已移除主紀錄與資源不提供錯誤預選或默認開啟另一項；空白情境清單提供建立入口。
- 常用資源用原生按鈕與 disclosure，不建立另一個模態視窗；Tab、Esc、焦點回復與面板外關閉均有自動化驗收。

Windows 實際版面、不同縮放與原生資源開啟仍需實機驗收。

## v1.127.0 情境浮層驗收

- 主頁不再有 context-bar 橫列；現有 header 內只放情境觸發按鈕，操作內容為固定定位且預設隱藏的原生 Popover。
- 同一浮層直接選情境及開資源，不建立第二層資源浮層；沒有情境時可直接建立。
- 驗收按鈕展開狀態、初始焦點、Esc／關閉回復焦點、點外／焦點移出關閉，以及原生 light-dismiss 通知同步。
- 驗收視窗變窄及縮短後重新定位、限制浮層寬高；情境切換後可繼續操作，資源開啟成功才收起。
- 沿用原有切換保護與預選整合測試；Windows 實際版面、縮放及原生選單仍待實機驗收。

## v1.128.0 桌面工作情境驗收

- 真正獨立、無主視窗 parent 的原生視窗；sandbox、contextIsolation、固定 preload 介面及精確來源核對。主程式只保留啟動按鈕。
- 原生視窗模擬驗收：48px 圖示、280ms 懸停不 focus、離開延遲／進入取消、釘選及編輯／操作中不收合、螢幕邊界、獨立置頂與位置持久保存。
- 主視窗隱藏時桌面選情境不 show／focus 主視窗；以帶 nonce 的主 renderer 保留請求防止未儲存內容被清除，錯誤回覆來源／nonce 不採用。桌面編輯／忙碌時主視窗不能同時切換。
- 直接查看主紀錄、儲存檢視、工作集與追蹤檔案；結果 token 限定可操作內容、來源版本、追蹤快照及目前情境。文字以 textContent 顯示。
- 參數範本預覽再複製，修改參數使預覽失效；核對參數、情境、紀錄與範本版本，剪貼簿使用實際預覽文字；取消離開保留輸入。
- Windows 實機仍須核對：桌面多螢幕／縮放、圖示拖曳、懸停不搶目前應用程式焦點、置頂與原生工作集確認，以及安裝包。自動化 DOM／原生視窗模擬測試不等同此項驗收。
