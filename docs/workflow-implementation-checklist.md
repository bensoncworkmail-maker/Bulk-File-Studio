# 現行功能驗收清單（v1.130.0）

- 工具箱五個主要入口順序：情境包、參數範本、追蹤變更、離線 OCR、備份。其他工具及管理子頁仍可到達。
- 五項已移除功能：DOM、路由、功能搜尋、preload、IPC、執行服務與分析 worker 均清除；舊自動流程在紀錄寫入時不執行，舊設定仍可讀取與備份。
- 工作情境與浮動工具為不同原生視窗，可同時顯示；工作情境保持 sandbox、contextIsolation、固定 IPC 介面及精確來源核對。
- 24–64px 圖示自訂／重啟、懸停不 focus、釘選／忙碌／編輯時不收合、位置及寬版檢視保留。
- 追蹤表格元資料格式、排序、篩選、分頁、跨頁選取、複製與原結果 index／token 維持一致。
- 參數範本先預覽；編輯參數或資料版本改變後不能複製過期內容。切換情境保護未儲存內容。
- OCR 校正結果直接建立一般草稿；無收件匣標籤，儲存失敗交易回滾，不留下空草稿。
- 保留路徑修復、整理條件、文件預覽、作業中心、搬移 worker、多步復原、完整備份與試還原的回歸驗收。

完整來源盤點及全套測試範圍見 [本次檢查報告](function-review-v1.130.0-zh-Hant.md)。DOM 及原生視窗模擬不等同 Windows 實機視覺驗收；OCR、Everything、SMB、貼上、回收筒、多螢幕與 EXE 仍需實機確認。
