# 工具箱與浮動工具驗收

- 工具箱第一層提供工作集、參數範本、追蹤變更、離線 OCR、備份。其他工具與管理子頁可從工具箱開啟。
- 舊情境包可隨備份相容讀取。主視窗、浮動工具、設定及系統匣均已移除情境入口。
- 既有工作集可直接開啟。加入檔案、資料夾、收藏及紀錄後，可儲存、編輯並核對批次開啟的路徑。
- 開啟浮動工具自動收合後，切換到其他程式，查看紀錄仍顯示已載入的清單與詳情。
- 分別釘選兩筆紀錄，兩張便條應可各自移動、收合、展開及取消釘選。關閉應用程式後，保留未取消的紀錄釘選。
- 從外部文字欄位開啟常用文字分類選擇窗，以方向鍵及 Enter 選取。切換外部目標時，選擇窗應關閉。
- 更改 Everything 結果排序後，雙擊 ZIP 名稱欄開啟檔案，雙擊位置欄在檔案總管定位。
- 移除草稿中的路徑連結、複製附件或移動附件後，檔案仍留在各自的儲存位置。
- 核對文字範本、追蹤變更、OCR 存成草稿、路徑修復、整理規則、文件預覽及備份還原。
