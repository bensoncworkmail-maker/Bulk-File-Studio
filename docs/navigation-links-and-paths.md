# 頁面分工、網站與共享路徑

## 主選單與浮動工具

目前保留各頁的獨立內容。先釐清入口與用途，避免為減少按鈕而將不同工作塞入同一畫面。

| 頁面 | 建議 | 原因 |
| --- | --- | --- |
| 首頁 | 保留 | 提供常用入口與概況 |
| 資料工作區 | 保留 | 管理主表、明細與編輯表單 |
| 我的收藏 | 保留 | 依檔案位置、標籤管理資源，亦可沒有工作區紀錄 |
| 全域搜尋 | 保留完整結果頁；快捷鍵可用搜尋面板 | 跨收藏與工作區的結果需要獨立篩選及瀏覽空間 |
| 檔案工具 | 保留完整工作頁 | 批次改名／搬移需要來源、規則及確認預覽 |
| 日曆／看板 | 保留 | 跨表、日期與狀態的視圖，與資料表編輯不同 |
| 查看紀錄 | 保留 | 跨表、主紀錄、日期與欄位的快速檢閱，亦供浮動視窗使用；不是程式錯誤紀錄 |
| 工具箱 | 保留為次級功能集合 | 備份、修復、整理規則、片段及工作集放在同一分類入口 |

若後續要再減少主選單項目，優先將「查看紀錄」的主列入口收進工具箱，或將「檔案工具」入口歸入工具箱；內容視圖與既有快捷動作仍保留。這是導覽整理建議，本版沒有移除任何頁面或入口。

浮動工具內分頁負責「在同一視窗切換常駐內容」，快捷按鈕負責「叫出功能及選擇開啟方式」。兩者保留並共用資料；設定頁已補上用途說明。若只用外部選單或主視窗，可取消對應的工具內分頁。

## 紀錄中的網站

在「欄位與表格」新增類型為「網址」的欄位，再編輯紀錄填入完整 `https://...` 或 `http://...`。紀錄總覽會顯示「開啟網站 ↗」與「複製網址」。既有文字／長文字欄位若整個值是有效網址，也會出現相同操作；不解析筆記內文中的多個網址。

僅主動點擊時以系統預設瀏覽器開啟，不在本程式內載入網頁、不預先連線或產生網站預覽。只接受 HTTP／HTTPS，拒絕其他協定、帳號密碼及控制字元。開啟時重新依紀錄與欄位 ID 讀取目前值；已刪除資料不能開啟。網址值保存在既有欄位資料中，支援紀錄複製、Excel／資料包匯出匯入、修改歷史及共享合併。使用新「網址」欄位的共享來源，接收端也須更新至支援此欄位類型的版本（v1.84.0 起）。

## 映射磁碟轉為 UNC

例如 A 的 `R:` 對應 `\\10.10.2.60\temp`，希望 B 不對應 `R:` 也能開啟共享紀錄中的檔案：

1. 在「工具箱 → 批次修復路徑」，舊根路徑輸入 `R:\`，新根路徑輸入 `\\10.10.2.60\temp\`。
2. 按「預覽修復」，核對收藏／標籤位置、紀錄檔案連結及路徑文字欄位。`R:\testing\testingA.txt` 會變成 `\\10.10.2.60\temp\testing\testingA.txt`。
3. 選取要修改的項目，再按「確認修復所選連結」。系統確認後先建立完整備份，再更新路徑。原始檔案不搬移或複製。
4. A 在資料工作區對該主表「發佈共享更新」；這會產生該來源的新發布版本。B 拉取並核對差異後合併。
5. B 從已合併紀錄開啟 UNC 檔案。B 仍須能連線至內網共享並有檔案權限，但不需要相同的映射磁碟代號。

舊位置可以已失效；新根目錄及勾選的目標須存在、可存取且類型相符。預覽有期限，確認時會再核對資料與目標識別；目標變更、失聯或重複收藏會阻止套用。Windows 比對不分大小寫，且只替換完整目錄邊界，不會把 `R:\testingElse` 當成 `R:\testing`。

範圍包含所有有效紀錄（主表與明細）的直接檔案連結，以及整格為單一完整路徑的文字／長文字欄位。筆記、網址、多行混合文字、關聯 ID 與回收筒資料不做字串取代。更新保留紀錄 ID、關聯、標籤與筆記，每筆有變動紀錄的版本增加一次；共享差異合併可保留接收者未衝突的獨立修改。

收藏／標籤位置是各電腦的本機收藏資料，不會因發佈工作區來源就把整份收藏或標籤授權同步給 B。共享資料包中的紀錄檔案連結會攜帶 UNC 路徑；若 B 的本機收藏仍有舊 `R:` 路徑，B 可另行使用相同修復方式。

收藏清單載入不自動探測 UNC；狀態顯示「開啟時檢查」。開啟、定位或批次開啟時驗證內網主機與原檔案識別。主機名稱須解析至內網位址，不接受外部網路共享。檔案整理、實體搬移／刪除的原有本機路徑政策沒有擴充；本版處理的是連結修復及開啟。
