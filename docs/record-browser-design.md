## 查看紀錄

- 主視窗顯示標題與簡短說明；浮窗保留精簡外框，共用紀錄卡片與操作。
- 主搜尋列提供搜尋文字、表格及所屬主紀錄。「更多篩選」放置日期依據、起迄日、狀態／欄位及欄位值。「檢視」放置清單／卡片及排序。
- 快速日期為今天、最近 7 個日曆日（含今天）、本月完整日期範圍及不限日期；依目前日期欄位或原查看紀錄設定篩選，不另建資料來源。
- 目前條件按搜尋、主紀錄、日期及欄位分組顯示。移除欄位條件也清掉其欄位值，移除日期條件也清掉日期依據及起迄日；表格範圍與檢視選項維持原值。
- 結果顯示紀錄標題、所屬主紀錄、日期、表格、狀態及少量標籤。狀態優先使用目前選取的狀態欄，否則顯示表格第一個選項／勾選欄。標籤只顯示前三個，其餘顯示數量。
- 標題、箭頭與空白處仍在原頁展開／收合。詳情區分欄位資料、筆記與操作列；可建立提醒、前往工作區、收合或編輯釘選。另有「收合詳情」及「重新整理」。
- 筆數、摘要行數、可選表格、日期來源、排序、浮窗釘選與條件記憶沿用原設定及服務；沒有把篩選結果誤當成新增或刪除操作。

## 快速找功能與說明入口

「找功能」與「使用指南」從頂端移到資訊頁的支援區，Ctrl+K／F1 保留。功能搜尋每項分為分類、名稱、說明三行，使用自動高度、換行與獨立間距，避免通用固定高度按鈕造成文字重疊；標題列及關閉按鈕並排，說明文字與鍵盤提示置左。

指南也統一左對齊。Everything 的入門範例改為 `ext:pdf;docx;xlsx dm:last7days`，搜尋最近一週處理的常見文件；類型選擇不要再疊加影片等不相符條件。指南內容與離線 HTML 共用來源。

## 驗證界線

瀏覽器在本環境無法載入本機 file URL，原生視窗的輸入介面亦不可用，因此本次以 DOM 互動、資料模型、主程序整合與樣式範圍檢查驗證。實際 Windows 字型、DPI、浮窗尺寸及列印仍需實機確認。


## 浮窗密度與規劃頁層次

浮動查看紀錄以 `data-floating-logs` 標記內層 section，外層才是 `.tool-view`；獨立設定搜尋與表格選單兩欄、主紀錄另列。標題、日期與釘選同列，長標題省略但保留完整提示。移除重複箭頭後，原生標題按鈕仍提供鍵盤展開與 aria-expanded；空白處展開及文字選取保護沿用原流程。

主頁標題比照工具箱採用標題與說明兩行。日曆／看板以主題的 panel、surface-2 與邊框區分容器、內容及卡片，保留日期選取與焦點樣式。實際 Windows 視窗、縮放比例及各主題的視覺效果仍需桌面驗證；DOM 測試僅確認結構與互動。


浮窗在有主紀錄選單時，窄視窗讓搜尋獨立一列、兩個選單並排；560 px 以上三項同列。沒有主紀錄選單時，維持搜尋與表格並排。表格名稱、檢視標示與清除篩選共用摘要列，筆數或錯誤內容仍可換行；只看釘選的隱藏規則保留，主頁摘要結構不變。

追蹤篩選說明改為絕對定位提示，不佔版面高度；懸停或聚焦開啟、Esc 可關閉，並由 aria-describedby 提供說明關聯。參考 [W3C Tooltip Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)。
