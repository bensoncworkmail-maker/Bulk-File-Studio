# 工作區貼上圖片

1. 在資料工作區新增或編輯一筆紀錄，切到「筆記」分頁。
2. 複製截圖，在筆記欄按 Ctrl+V；多行文字欄也支援，貼上後會顯示筆記分頁的圖片。
3. 圖片以縮圖顯示，點圖放大，使用「上一張／下一張」或鍵盤 ←／→ 切換同一組縮圖，Esc 關閉預覽。拖曳預覽視窗右下角可調整寬高，下次開啟沿用該尺寸。也可在「設定 → 外觀與版面」的視窗尺寸清單中選擇「工作區圖片預覽」，輸入寬高或還原預設。按「移除」可解除圖片連結。文字內容維持純文字，不會被圖片取代。
4. 按「儲存紀錄」後，圖片才寫入目標表格的附件資料夾（workspace-files），並成為此紀錄的檔案連結。重新開啟紀錄可繼續預覽；詳情面板也顯示圖片縮圖。
5. 取消編輯不會保存本次新圖片。已保存的圖片移除後只解除紀錄連結，原圖仍保留，避免影響複製紀錄、修改歷史或其他引用。

從草稿筆記建立工作區紀錄時，可在「送出附件」選擇保留現有路徑，或將拖入檔案、資料夾與貼上的圖片複製到目標表格的附件資料夾。

每次編輯最多加入 8 張 PNG，每張最多 5 MB、寬高各 4096 像素，本次合計上限 20 MB。準備圖片期間先等待再儲存；若儲存失敗，表單保留圖片，主程序會清理該次新建的檔案，可修正問題後重試。

完整備份會封裝標示「貼上的圖片」的檔案；達既有備份附件數量或容量上限時，仍會在略過清單說明。還原後繼續保存圖片標示，後續備份仍會包含。一般工作區資料包與資料夾共享沿用檔案位置連結，並不直接嵌入圖片內容；跨電腦搬移圖片請使用包含附件的完整備份。

Windows 截圖剪貼簿及原生放大視窗仍需實機驗收；已以 renderer／主程序單元與整合測試驗證貼上、取消、儲存失敗清理、重新開啟及完整備份。
