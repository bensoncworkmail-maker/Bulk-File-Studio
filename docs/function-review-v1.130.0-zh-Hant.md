# 全功能重新檢查（v1.130.0）

本次以目前程式碼為準重新盤點全部 222 個 JS／HTML／CSS 來源、10 個頁面、12 個工具入口、31 項功能導覽與 263 個設定。完整檔案／函式索引見 [應用程式功能盤點](app-function-audit.md)。這份報告區分自動化／靜態驗證與 Windows 原生實機驗收，不把後者當作已通過。

## 本次變更

| 範圍 | 最終狀態 |
| --- | --- |
| 工作情境 | 恢復獨立 BrowserWindow，不使用浮動工具視窗；可同時顯示，各自保存位置與置頂 |
| 圖示及表格 | 保留 24–64px 圖示、懸停展開、面板模式及追蹤結果四欄表格／排序／篩選／分頁 |
| 五項刪除功能 | 主表彙總、重複檔分析、檔案比較、自動流程、收件匣：清除 UI、路由、功能目錄、相關 preload／IPC、服務與分析 worker |
| 舊自動流程 | 無紀錄事件執行路徑、無預覽／執行 IPC；舊 enabled 定義仍可讀取，但新紀錄不產生自動草稿／提醒／欄位修改 |
| OCR | 校正後直接建立原有草稿筆記；失敗交易回滾，不建立收件匣來源標籤 |
| 既有資料 | 保留草稿、紀錄、舊設定、執行歷程及轉入收據；不破壞性刪除使用者資料。相容讀取不提供已移除功能的執行能力 |

## 檢查中修正的生命週期問題

主視窗真正關閉時，一併銷毀獨立工作情境，避免只剩桌面工具視窗而讓程式留在背景。隱藏至系統匣仍沿用原有提前返回的路徑，保留桌面工具。新增原生視窗生命週期回歸測試。

## 可重現驗證

- `npm test`：**1,219 項通過，0 失敗**。執行全部現行測試；刪除功能的舊使用案例移除，新增能力不可呼叫、舊自動流程不執行、OCR 直接存草稿與獨立視窗回歸案例。最終結果亦記錄於本次 PR。
- `npm run check:app`：檢查全部來源、本機依賴、頁面與工具、功能導覽、設定預設／分類／控制項、指南版本／產物與已移除工具不可到達。
- `node build/update-changelog.js --check`、`git diff --check`：檢查版本與變更格式。

來源與安全檢查參照 [Electron 官方安全指南](https://www.electronjs.org/docs/latest/tutorial/security)，核對隔離、沙箱、限制導覽／新視窗及 IPC 來源。這是針對本次範圍的檢查，並非完整安全認證。本環境未啟動 Windows 桌面程式或產生 EXE。
