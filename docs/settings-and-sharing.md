# 設定與共享邏輯檢查（v1.45.0）

檢查日期：2026-11-02。涵蓋共享資料包、預覽與確認、工作區顯示，以及設定綁定、驗證、搜尋、匯出與重設。這是程式邏輯及測試檢查；Windows 視窗、通知、UNC/SMB 與安裝包仍需實機驗證。

## 儲存與授權界線

| 類型 | 儲存位置／擁有者 | 行為 |
| --- | --- | --- |
| 工作區顯示、一般／共享手動匯入預設 | renderer 設定 `brs-settings-v1` | 正規化後保存；支援搜尋、匯出設定與分類還原。兩種手動預設互相獨立。 |
| 浮動工具、桌面偏好 | desktop-state | 由主程序驗證與保存；介面接收最新狀態。 |
| 共享資料夾、啟用、間隔、接收策略、跟隨來源、已處理包、通知選項 | `workspace-share.json`／NotesShare | 不隨介面還原或一般設定匯出傳到另一台電腦；共享視窗與設定頁的接收控制同步。 |
| 紀錄與版本、修改歷史 | `workspace.sqlite`／NotesStore | 預覽不寫入；確認檢查工作區修訂，建立備份後以交易寫入。 |
| 已退役的群組導覽偏好 | renderer 舊偏好 | 保留相容，設定頁隱藏且搜尋排除；不影響主表導覽。未刪除資料關聯。 |

82 個介面綁定、55 個桌面綁定已核對對應控制項與預設；新選項遵循既有正規化與分類設定機制。沒有新增網路更新服務或啟用共享的隱含動作。

## 本次修正

1. 相同資料過多時，重要差異難找：預設只看有差異；數量按鈕可篩選，相同項目仍可查看。略過相同內容不顯示為內容變更。
2. 「變更後」在略過模式可能被誤讀為會寫入：改為來源值，明示不套用；更新／來源複製才顯示匯入後值。
3. 本機紀錄版本與來源發布修訂容易混淆：紀錄摘要加上本機標示，來源與本機工作區修訂放進版本資訊。
4. 共享視窗設定占滿空間：預設以更新清單為主；完整設定與資料包識別資訊可展開，保留單一內容捲動區及固定操作區。
5. 主從操作說明開關未隱藏已選主檔摘要：已修正；精簡版長摘要省略，仍提供完整文字提示。
6. 通知偏好保存失敗只顯示錯誤、未回復勾選：失敗後重新取得已保存狀態，兩處控制項一起回復。忽略策略不顯示舊通知的匯入按鈕。
7. 共用快捷列與資料快捷列命名不清：分成「共享快捷操作」及「資料操作」，各自有既有／新增顯示開關；不以顯示開關代替共享授權。

## 匯入及快捷操作規則

- 比較仍按 ID，不按名稱。另存副本建立新 ID，預覽會顯示新增；若要追蹤同一來源，選更新或來源複製。
- 更新保留本機獨有資料；來源複製以來源包取代工作區，缺少項目會列入移除，且再次確認。兩者皆先備份。
- 內容相同仍允許確認，供記住已接收資料包或建立跟隨基準；不新增空白紀錄歷史。
- 快捷檢查只查已啟用的共享位置，可能因既有自動接收設定觸發受保護的更新；有編輯／預覽時自動接收會暫停。快捷發佈仍確認，快捷預覽不會自動匯入。
- 自動接收仍固定使用更新模式，不採用手動預設；共享自動發佈與自動接收互斥，本機修改或來源修訂倒退會停止套用。
- 清單顯示的發布時間與來源取自資料包名稱，完整資訊可展開。名稱不是身分驗證；來源 ID 不等於數位簽章。

## v1.46.0 補充

- 共享設定新增 publishScope／receiveScope，按主表 ID 篩選，保存後才生效；改接收範圍或跟隨來源會撤銷舊基準和待確認預覽。預設仍不啟用共享。
- 新增 floatingCaptureKeepValues，預設保留連續新增的欄位及標籤，可搜尋、匯出與分類還原；名稱與筆記每筆清空。
- 新預覽失敗會撤銷舊確認權限，避免誤套用上一次的比較。
- Windows 登記核對只讀固定的 HKCU 本程式名稱及舊版 AppUserModelId，經 PowerShell UTF-8 輸出支援中文路徑；讀取不執行登記的命令，無須管理員權限。核准資訊未知時明示；只有使用者切換才寫入，並只移除已驗證屬於目前程式的舊名稱。系統限制讀取時會報告無法驗證，不假定已啟用。
- 分類導覽固定每個選項內容高度，避免捲動 flex 容器壓縮按鈕；焦點框改在框內。快捷表單改成一個欄位捲動區，底部操作在外。

Electron 已有路徑含空格導致啟動項回讀遺漏的修正；本程式亦處理舊名稱與實際安裝位置不一致的情況。不能單憑截圖確定使用者電腦的原因，仍需新版 Windows 安裝版實機核對。
