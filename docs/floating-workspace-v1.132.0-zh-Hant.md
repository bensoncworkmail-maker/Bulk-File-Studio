# 浮動工作台與獨立追蹤頁（v1.132.0）

## 草稿圖片依名稱排序

新貼上圖片以同一份草稿的 UUID 為共同前綴，後接六位流水號，例如：

- `baa9c89f-f19e-4c1b-99a7-fa25afb0d335-000001.png`
- `baa9c89f-f19e-4c1b-99a7-fa25afb0d335-000002.png`
- `baa9c89f-f19e-4c1b-99a7-fa25afb0d335-000010.png`

補零讓一般字串排序及 Explorer 自然排序都符合圖片加入順序。面板仍顯示「貼上的圖片 1」等易讀名稱。移除中間附件不重編其他圖片；遇到檔名碰撞會使用下一個可用編號，不覆蓋檔案。新複製／搬移附件繼續與圖片放在該草稿根目錄。

舊 UUID 圖片及「貼上的圖片 N.png」仍能預覽，既有連結不改名。改名規則只套用新圖片；舊草稿混合兩種命名時，舊圖片不會自動重新排序或搬移。

## Everything 追蹤為獨立頁

頂端「Everything 追蹤」直接進入原來的搜尋與結果介面。首頁、功能搜尋、儲存搜尋及浮動工具入口都導向新頁；原追蹤 ID、搜尋式、標籤、欄位、排序及選取偏好繼續沿用。離開頁面即停用其定時更新，返回再按原規則更新。

「我的收藏」只保留「檔案與資料夾」和「工作區紀錄與表格」，支援左右方向鍵、Home／End 及分頁記憶。舊設定曾記住 Everything 收藏分頁者，收藏回復檔案分頁，不再偷偷切到追蹤頁。可在設定 → 啟動，明確將啟動頁設為 Everything 追蹤。

## 依原型升級浮動工具

「設定 → 浮動工具 → 浮動工具入口」選擇模式；也可在工具列空白處按右鍵，選「入口模式」。為保留既有使用方式，預設仍是傳統工具列。

| 入口 | 收合時 | 展開時 |
| --- | --- | --- |
| 傳統工具列 | 沿用原有按鈕與自訂寬度 | 原有內容分頁 |
| 側邊工具列 | 56 × 352px 直向入口 | 側邊快捷列＋內容；窄於 420px 時入口改為橫列 |
| Dock 工具列 | 392 × 56px 橫向入口 | 快捷列位於內容底部 |
| 懸浮球 | 56 × 56px 的 B 入口 | 點擊或懸停約 280ms 展開 |

尺寸會受螢幕工作區限制。拖曳入口的空白邊緣移動；點 B 或原有收合按鈕切換展開。各模式共用同一浮動工具與資料，不會複製收藏。Dock 為可拖曳工具列，不佔用 Windows 工作列或保留螢幕工作區。

快捷入口：常用文字、剪貼簿、收藏／工作區、日曆、Everything、工作情境、草稿及設定。停用的內容分頁會停用相應入口；可在原有「浮動內容」設定勾選啟用。升級者已有的分頁選擇保持原樣，因此剪貼簿可能需要先啟用。

「記住上次展開的浮動分頁」跨重啟保存；停用時使用原有預設分頁。「滑鼠離開且浮窗未取得焦點時自動收合」預設關閉；啟用後等待約 650ms，輸入中、有開啟對話框、原生選單或檔案處理時不自動收合。

## 常用工作例子

| 需要 | 操作 |
| --- | --- |
| 一邊回覆客戶、一邊查日期 | 在日曆或常用文字分頁按「↗ 獨立面板」，原有原生面板會獨立開啟；主工作台可切到其他分頁 |
| 在另一個程式切換客戶 | 點工作情境入口，依其既有桌面浮動／程式內設定開啟；不再把工作情境合併成浮動工具的資料分頁 |
| 隨手記下圖片和檔案 | 點草稿入口開啟原有草稿筆記，貼圖及拖入附件；沒有另一套草稿儲存區 |
| 保存幾段剪貼文字待用 | 開剪貼簿分頁，按「擷取目前文字」；稍後搜尋並複製，再在目標程式按 Ctrl+V |
| 用最近修改條件找文件 | 點 ⌕ 進入獨立 Everything 頁，沿用儲存搜尋與結果操作 |

剪貼文字不背景監聽、不寫入磁碟、不納入備份；本次執行最多 20 項，每項最多 20,000 字，重複文字移到最前。可逐項移除或清空，關閉整個程式後清除；只隱藏工具不會清除。圖片及檔案仍交由草稿附件與既有檔案功能處理。複製只接受已保存項目 ID，失效項目會停止；清空會讓未完成的擷取失效。

## 原型對照與界線

此次移植入口外觀、內容切換、卡片層次、手動剪貼文字、分頁記憶及獨立面板入口；原有置頂、透明度、尺寸及快捷鍵設定繼續生效。原型中的假客戶、假日曆及假草稿沒有搬入正式資料。

原型中尚未具備後端的「偵測全螢幕應用並隱藏」「每螢幕分別保存位置」「自動辨識遠端桌面」不顯示為可用開關。位置沿用原有跨螢幕可見範圍修正；文字的立即貼上沿用原有目標核對機制。這次剪貼文字分頁提供明確的複製操作，沒有聲稱能自動判斷遠端輸入目標。

官方技術參考：[Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)、[Electron Clipboard](https://www.electronjs.org/docs/latest/api/clipboard)。

全套 1,230 項測試通過；另驗證入口實際尺寸、拖曳與重啟偏好、收藏分頁遷移、追蹤頁快捷鍵／更新生命週期、剪貼文字的非同步清空保護與來源驗證。check:app 盤點 227 個來源、11 頁、11 個工具、29 個功能入口及 268 個設定。版本及兩份離線指南一致性檢查通過。

測試環境的 Chromium 啟動受限制，未完成瀏覽器截圖或 Windows 實機視覺驗收；DPI、多螢幕、原生拖曳、置頂、Everything 及外部貼上仍需 Windows 確認。
