# 浮動工具內容分頁

在「設定 → 浮動工具 → 浮動內容分頁」可以勾選、排序日曆／看板和常用文字片段，並設定第一次開啟時使用的分頁。日曆可預設月曆、行程清單或狀態看板。文字片段可預設精簡或內容預覽，也可預填搜尋。兩個分頁在同一個浮動視窗展開，切換時保留各自的本次條件。「收藏／工作區」提供收藏、標籤、工作區及混合檢視，預設與分頁及快捷動作共用一列。

收合時可透過標題列右鍵選單直接展開已啟用的分頁。此入口可在設定停用。從主視窗開啟日曆或片段的浮動檢視時，會選取同一個浮動視窗的對應分頁。「查看紀錄」可獨立開啟。

## 快捷動作與外部選單

在「設定 → 浮動工具 → 編輯快捷動作」選「日曆／看板」或「常用文字片段」。開啟方式可選「浮動工具內」、「外部選單」或「主視窗」。若已在收合設定中加入該快捷按鈕，收合時也可使用外部選單。

浮動月曆預設以圓點標記有行程的日期。可在「浮動內容分頁 → 浮動月曆行程標記」改為在日期下方顯示筆數。滑鼠停在日期上也會顯示確切筆數。點日期開啟當天的外部選單，點選項目進入原紀錄。可在浮動工具內切換行程清單及看板，或按 ↗ 開啟完整日曆／看板。

外部選單在快捷按鈕附近開啟，片段依分類分組，沒有分類的片段放在「未分類」。在浮動工具內或外部選單點選文字片段即可複製。片段包含 `{{customer}}` 時，可在浮動工具內先填「客戶／稱呼」再複製。

## 加入內建分頁

1. 在 `floating-panels-model.js` 登記分頁 ID 與顯示名稱。桌面設定與右鍵選單使用這份清單。
2. 在 `floating-panels.js` 加入本機元件。元件提供 `mount(root, api, prefs)`，回傳 `refresh()` 與 `dispose()`。宿主處理視窗位置、收合、順序與切換。元件處理內容與自己的查詢狀態。
3. 如需原生能力，在 `main.js` 與 preload 加入對應的具名操作，依元件類型核對參數及允許的行為。現有日曆只能讀取行程、看板速覽與開啟紀錄。文字片段可以讀取和複製已保存內容。設定只儲存元件 ID 及偏好。

此架構供隨程式打包的元件使用。浮動視窗的沙箱及離線政策照常套用。

## 快捷按鈕的標籤外部選單項目

在「設定 → 浮動工具 → 編輯快捷動作」選擇「開啟標籤收藏清單（外部選單）」，展開編輯後可在「外部選單顯示的操作」獨立勾選：

- 在主視窗顯示此分類
- 複製此篩選結果全部路徑
- 批次開啟檔案／資料夾
- 批次開啟所在資料夾

每個快捷按鈕各自保存設定，含其多標籤分類子選單。全部取消會只保留收藏項目，不會顯示多餘分隔線；不影響浮動工具本身的其他標籤入口。既有按鈕預設全部顯示。批次操作仍須確認並遵守可用路徑及數量限制。

## 指定文字片段立即貼上

在「設定 → 浮動工具 → 編輯快捷動作」選擇「立即貼上指定文字片段」，選片段並設定全域快捷鍵（預設未設定）。先將游標放到另一個程式的文字欄位，再按快捷鍵。文字會取代剪貼簿，嘗試送出 Ctrl+V，不會按 Enter；{{today}} 展開今天，{{customer}} 留空。複製模式的外部選單及片段本身的快捷鍵仍只複製。

僅支援 Windows，使用內建 PowerShell 與 user32，不下載元件或連線。請在目標程式使用快捷鍵；在浮動按鈕上直接點擊時若焦點仍在本程式，會保留已複製文字並提示手動貼上。原生程序觀察到目標變更或修飾鍵超過 2 秒未放開會取消。管理員程式或限制鍵盤輸入的欄位可能不接受貼上；送出成功仍須核對欄位。剪貼簿文字不會自動還原，避免覆蓋稍後複製的內容。Windows 實際行為需實機驗證。

## 匯入常用文字片段

工具箱 → 常用文字片段 →「匯入 Excel／CSV／貼上文字」。選 UTF-8 .csv 或 .xlsx（可拖放），或直接貼上 CSV／從 Excel 複製的表格。第一列必須有名稱與文字內容，分類選填，也接受 name、category、body。例如：

```csv
name,category,body
問候,工作,"你好，{{customer}}"
回覆,工作,"已收到，謝謝。"
```

CSV 內含逗號、換行或雙引號時須以雙引號包住，內容的雙引號寫成兩個雙引號。Excel 可選工作表，只讀已儲存值，不執行公式。預覽前 50 筆，列出錯誤；有錯誤時整批不寫入。來源或片段有變更需重新預覽。

只新增、不覆蓋，名稱／分類／內容完全相同會略過；同名但內容不同會另增一筆。匯入不設定快捷鍵。每格內容上限 20,000 字，預覽資料最多 2 MB，匯入後最多 500 個片段。確認前將工具資料 JSON 備份至程式使用者資料目錄的 snippet-import-backups。

## 先選片段，再複製或貼上

「設定 → 浮動工具 → 編輯快捷動作」，操作類型選「常用文字片段」，可指定「選取片段後的動作」：

- 複製：保留原有開啟方式，點選片段只複製文字。
- 立即貼上：全域快捷鍵使用保留目標焦點的外部分類選擇窗（v1.82.0 起）。先在其他程式的文字欄位按此按鈕的全域快捷鍵，等選擇窗出現後用滑鼠選片段；關閉選擇窗後，核對原目標仍在前景才送出一次 Ctrl+V。

目標須在 60 秒內使用。會核對視窗仍存在、程序 ID 及前景；若已切到其他程式，不會強制轉移。Windows 可拒絕啟用目標或送出鍵盤輸入，尤其不同權限程式，須實機核對。若用滑鼠直接按浮動按鈕，當時無法取得外部目標，選片段後僅複製並提示手動貼上。未取得有效目標也不會向任意視窗送出貼上。原有「立即貼上指定文字片段」適合固定片段，仍保留。

### 選單開啟速度

v1.81.2 起，只要有啟用的貼上快捷動作，程式便預先載入一個本機 Windows 輔助程序，後續捕捉目標及貼上共用它。確認修飾鍵已放開後，選單只保留約 40 毫秒的穩定等待，不再因錯過放鍵事件額外等候 1.5 秒。這是程式設定的等待時間，不是完整開啟時間保證；剛啟用或程序重啟時仍可能等候初始化，按住快捷鍵也會等候放開。

程序中斷、逾時會取消所有待執行請求，不自動重送貼上，下次操作再啟動。停用所有貼上快捷動作或關閉程式時清理程序。僅使用 stdin/stdout 本機管道，不開網路連線，不安裝背景服務。既有目標識別、60 秒期限、前景視窗及修飾鍵核對保留。

### 選取後的等待

v1.81.3 起，輔助程序會在回報可用前預先準備原生貼上方法，初始化放在開啟選單前。選取片段會先複製，依原生選單實際關閉的通知繼續，不再固定等待 80 毫秒。

選單綁定當次輔助程序的啟動識別。選單開著時若程序中斷／重新啟動，選取後不會再等初始化，會保留已複製文字並提示手動 Ctrl+V 或重新開啟選單。若選單超過 500 毫秒仍未回報關閉，同樣停止自動貼上。Windows 切回目標及放鍵仍需等待系統完成；不保證零延遲，需實機驗證。

### 首次選取未貼上的排查

v1.81.4 針對焦點恢復流程增加以下處理：捕捉不到目標時不再開啟自動貼上選單，顯示原因；選單關閉後先釋放浮動工具焦點，容許暫時沒有前景視窗的啟用過渡，最多 750 毫秒恢復原目標，並以 WM_NULL 訊息確認目標處理完啟用，再檢查前景與程序 ID 才送出 Ctrl+V。若目標超過 300 毫秒未回應則取消，不重複送出貼上。

未能完成時顯示桌面通知（需 Windows 允許通知），具體錯誤也會寫入錯誤紀錄。文字保留在剪貼簿，可手動貼上。不會略過不同程序、已關閉視窗或使用者已切到其他程式的檢查。這些是針對程式碼已知判斷的修正；仍需 Windows 實機驗證首次選取是否改善，不能保證所有程式都接受模擬貼上。

### v1.81.5 焦點恢復修正

錯誤「前景視窗與原目標不符」表示尚未送出 Ctrl+V 就被檢查取消，並非初始化仍未完成。v1.81.5 移除上一版在核對前主動 blur 浮動工具的步驟，讓原生程式直接恢復已記住的目標，不先由 Windows 選另一個視窗。真正切到其他外部視窗仍會取消；不自動重送貼上。

若仍發生，錯誤文字會包含 stage、foreground／expected 視窗識別與 foregroundPid／expectedPid／appPid／helperPid，無片段內容或視窗標題，可用於核對到底哪個視窗取得焦點。這個來源碼修正已經過自動測試，但 Windows 實際初次選取情況仍需實機確認。定時備份遇到其他作業忙碌會略過，留待下一次檢查，不影響貼上。


### v1.82.0 保留目標焦點的選擇窗

v1.81.5 的「無法回到原目標」表示選片段後恢復前景未成功，並非仍在初始化。Windows 會限制背景程序啟用其他視窗；反覆延長等待仍可能失敗。v1.82.0 改為 `focusable:false` 的獨立分類選擇窗，只使用 `showInactive()` 顯示，不先啟用浮動工具或原生選單。此快捷鍵流程不再呼叫 `SetForegroundWindow`。

請先按一下目標文字欄位，再按「常用文字片段 → 立即貼上」快捷鍵。選擇窗支援滑鼠展開／收合分類、捲動及點選片段，保留原欄位的鍵盤焦點。為此不提供在窗內打字搜尋或方向鍵選取；清單沿用已設定的浮動片段搜尋。按 Esc、關閉或超過 60 秒會取消，再次按快捷鍵會重建選擇窗。Esc 僅在選擇窗開啟期間暫時註冊；若按鍵註冊失敗，可按關閉。

原目標已關閉、失去前景、程序改變、超時或輔助程序重啟時均取消，不強制搶回焦點、不重試貼上。片段選取只接受選擇窗本身的請求，選取一次即銷毀視窗，避免重複送出。失敗仍保留已複製文字並提示手動貼上。直接用滑鼠按浮動按鈕仍只複製；要自動貼到其他程式，請從該程式使用全域快捷鍵。複製模式維持原生分類選單。

自動測試核對不啟用的視窗設定、目標傳遞、單次選取、關閉清理及拒絕其他視窗呼叫；無法替代 Windows 的實際焦點與輸入測試。更新後仍須核對冷啟動與輔助程序重啟後首次選取，並在記事本、瀏覽器文字欄位及不同權限程式驗證。
