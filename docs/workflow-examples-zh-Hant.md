# 工具箱：用途、情境與例子

工具箱提供工作集、參數範本、追蹤變更、離線 OCR、備份及檔案工具。工作集操作見工具箱指南。下列工具的操作例子與應用程式共用內容來源。

| 功能 | 何時使用 |
| --- | --- |
| 參數範本 | 經常回覆相似訊息，但客戶、主旨或日期每次不同。 |
| 條件規則 | 整理報價、合約或報表時，單純副檔名篩選不足，或擔心同一檔案被分到不同資料夾。 |
| 追蹤變更 | 持續留意客戶資料夾、最近修改文件或某類檔案，而不想每次靠記憶比較清單。 |
| 離線 OCR | 收到掃描收據、截圖或拍照文字，想減少重新打字。 |
| 備份 | 大量匯入、修改表格、換電腦或整理資料前，先留下可還原版本。 |

## 參數範本（N07）

**用途**：把固定文字變成可填欄位的範本，並帶入日期、剪貼簿或所選紀錄。

**適用情境**：經常回覆相似訊息，但客戶、主旨或日期每次不同。

**例子**：範本為「{{record.title}} 您好，關於 {{subject}}，我們將於 {{today}} 回覆。」；選客戶 A 並填主旨「新報價」，即可預覽完整文字。

1. 先在「參數範本 → 文字範本管理」建立含參數的文字。
2. 在本頁選範本及紀錄，填寫動態出現的參數欄位。
3. 按「預覽內容」，核對後按「複製內容」；Windows 亦可明確選擇貼到前一視窗。

**結果**：同一範本產生不同內容，缺少必要參數時會停止產生。

**留意**：複製不會自動傳送訊息；原生貼上若無法確認目標，文字仍保留於剪貼簿。

## 條件規則（N08）

**用途**：用 AND／OR 群組描述檔案條件，檢視每條規則為何符合，以及多規則的目的地衝突。

**適用情境**：整理報價、合約或報表時，單純副檔名篩選不足，或擔心同一檔案被分到不同資料夾。

**例子**：設定「副檔名＝pdf AND（檔名包含『報價』OR『合約』）」；若另一條規則把同一 PDF 指向不同目的地，預覽會標出衝突。

1. 先在工具箱建立整理規則，設定前綴、目的地及標籤。
2. 在本頁選規則，建立 AND／OR 條件樹並儲存。
3. 選來源後按「檢查所有規則與衝突」，核對解釋，再前往整理規則套用。

**結果**：每個來源都能查看實際值與符合結果；使用者選擇要套用的規則。

**留意**：儲存條件樹不會立即整理檔案；目的地衝突不會自動決定優先順序。

## 追蹤變更（N03）

**用途**：比較同一 Everything 搜尋前後的快照，查看新增、移出結果、屬性變更及可能改名。

**適用情境**：持續留意客戶資料夾、最近修改文件或某類檔案，而不想每次靠記憶比較清單。

**例子**：追蹤「客戶 A 最近 7 天的 PDF」；第一次建立基準，下一次檢查可看到新增的兩份報價及可能改名的文件。

1. 先建立 Everything 追蹤搜尋，再在本頁按「立即檢查」建立基準。
2. 稍後再次檢查，或自行啟用背景監控。
3. 查看差異及最近變更紀錄，確認後標示已讀。

**結果**：變更內容保留供檢視；背景監控在程式執行期間每分鐘循序檢查。

**留意**：「移出結果」不一定代表刪除，也可能不再符合日期條件；截斷或略過的結果不是完整磁碟清單。

## 離線 OCR（N12）

**用途**：把圖片中的文字辨識出來，人工校正後連同來源保存為草稿。

**適用情境**：收到掃描收據、截圖或拍照文字，想減少重新打字。

**例子**：選一張收據 JPG，辨識後核對日期及「9,800」等金額，修正錯字，再存成草稿，之後轉到費用或跟進紀錄。

1. 選一張支援的圖片，語言留空使用系統語言，或填入語言代碼。
2. 按「辨識圖片」，需要時用來源的「預覽」對照原圖。
3. 校正文字後按「校正完成，存成草稿」。

**結果**：保存可再整理的草稿與圖片來源，沒有自動寫入金額等工作區欄位。

**留意**：需要 Windows 10／11 及可用 OCR 語言元件；辨識可能有誤，須核對。原生功能仍需實機驗收。

## 備份（N02）

**用途**：保存工作區、草稿、工具與流程設定，並核對歷史／附件涵蓋範圍及試還原結果。

**適用情境**：大量匯入、修改表格、換電腦或整理資料前，先留下可還原版本。

**例子**：匯入客戶 Excel 前，建立包含草稿、紀錄歷史及可封裝 PDF 的備份；先試還原。匯入結果不符預期時，預覽並確認還原該份備份。

1. 開啟工具箱「備份」，選擇是否包含歷史及紀錄文件，建立備份。
2. 檢查未封裝原因，需要時匯出到另一個可靠位置，並按「試還原」。
3. 真正還原前核對資料數量與涵蓋清單，再確認還原；系統會先備份目前狀態。

**結果**：試還原使用獨立暫存資料庫，不改變目前資料；真正還原會取代相應的應用程式資料。

**留意**：不是整部電腦的備份；資料夾內容不封裝，附件有大小／數量限制，未封裝文件仍為連結。
