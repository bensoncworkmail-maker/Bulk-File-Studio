# 工具箱：用途、情境與例子

工具箱保留七個常用入口：收件匣、情境包、參數範本、追蹤變更、離線 OCR、自動流程及備份。其餘入口在「其他工具」或相關工具內。這份手冊保留原有 14 項能力的情境與例子；來源收集已併入收件匣，目的地則放在操作內，不是額外分頁。說明與應用程式共用內容來源；Ctrl+Shift+K 直接開收件匣，有檔案選取時 Ctrl+K 可帶入來源。

| 功能 | 何時使用 |
| --- | --- |
| 選取來源與快速收集 | 在 Everything 找到文件後，需要立即記下跟進內容。 |
| 收件匣 | 接電話、收到文件或想到待辦時，尚未決定要放在哪張表格。 |
| 情境包 | 每天在多個客戶或專案之間切換，需要快速找到各自的資料入口。 |
| 主表彙總 | 想知道每位客戶有多少未完成跟進、合約總額或最早到期日。 |
| 參數範本 | 經常回覆相似訊息，但客戶、主旨或日期每次不同。 |
| 條件規則 | 整理報價、合約或報表時，單純副檔名篩選不足，或擔心同一檔案被分到不同資料夾。 |
| 追蹤變更 | 持續留意客戶資料夾、最近修改文件或某類檔案，而不想每次靠記憶比較清單。 |
| 作業中心 | 需要分批整理多組檔案，或希望改錯時逐步回到之前的檔名與位置。 |
| 重複檔 | 下載、Email 附件及備份資料夾累積許多副本，想確認哪些內容真的相同。 |
| 檔案比較 | 收到新版文字內容，或想檢查兩個資料夾是否一致。 |
| 離線 OCR | 收到掃描收據、截圖或拍照文字，想減少重新打字。 |
| 自動流程 | 有固定的資料處理步驟，希望減少重複操作。 |
| 操作內目的地快選 | 經常把匯出或搬移結果放到幾個固定位置。 |
| 備份 | 大量匯入、修改表格、換電腦或整理資料前，先留下可還原版本。 |

## 選取來源與快速收集（N04）

**用途**：把目前選取的檔案帶進工具箱收件匣，預覽後連同文字存成草稿。

**適用情境**：在 Everything 找到文件後，需要立即記下跟進內容。

**例子**：選取「客戶 A 報價.pdf」，按 Ctrl+K，核對來源，再輸入「星期五前回覆」並儲存到收件匣。

1. 在 Everything 或一般收藏選取檔案，按 Ctrl+K，開啟工具箱收件匣。
2. 展開「附加檔案（選填）」，按來源旁的「預覽」核對。
3. 輸入標題與內容，按「儲存到收件匣」。

**結果**：草稿保留文字及來源連結，可稍後整理到工作區。

**留意**：已併入收件匣，不再另設動作面板；需要搬移或分析時，展開工具箱「其他工具」。

## 收件匣（N09）

**用途**：先收集文字、剪貼簿內容或檔案來源成為草稿，之後再整理到工作區。

**適用情境**：接電話、收到文件或想到待辦時，尚未決定要放在哪張表格。

**例子**：記下「客戶 A 要求星期五前回覆」，加入報價 PDF，儲存草稿；稍後選「跟進紀錄」表格及客戶 A，轉成正式明細。

1. 輸入標題與內容，需要時先從剪貼簿填入，再核對修改。
2. 按「儲存到收件匣」。
3. 展開草稿的「整理到工作區」，選表格；明細表需選主紀錄，再按「建立紀錄並移出草稿」。

**結果**：正式紀錄保留草稿文字及來源連結；同一草稿重試轉入會回到原紀錄。

**留意**：儲存到收件匣仍是草稿；轉為紀錄後才加入工作區。移除來源標籤不會刪除原始檔案。

## 情境包（N05）

**用途**：把同一客戶或專案常用的主紀錄、工作集、追蹤搜尋、儲存檢視與文字範本放在一起。

**適用情境**：每天在多個客戶或專案之間切換，需要快速找到各自的資料入口。

**例子**：「客戶 A」情境包綁定 A 的主紀錄、報價工作集、最近文件追蹤、待跟進檢視及回覆範本；切換「客戶 B」時改用 B 的入口。

1. 輸入情境包名稱，選擇主紀錄及需要連結的既有資源。
2. 儲存後按「啟用情境」。
3. 使用包內按鈕開啟對應的工作集、搜尋、檢視或範本。

**結果**：目前啟用的情境跨重啟保留，工具箱可用該主紀錄預填收件匣及範本。

**留意**：情境包保存連結，不複製文件；儲存檢視要按對應入口才會開啟。

## 主表彙總（N06）

**用途**：從主紀錄的關聯明細計算筆數、數值合計、最小／最大值、最早／最遲日期或剩餘天數。

**適用情境**：想知道每位客戶有多少未完成跟進、合約總額或最早到期日。

**例子**：客戶 A 有兩份合約，金額分別是 12,000 與 8,000；設定金額合計後顯示 20,000。另可加「已完成＝false」條件計算未完成跟進數。

1. 新增彙總，選主表、明細來源表及指向主表的關聯欄位。
2. 選計算方式與數字／日期欄位，需要時加篩選條件，再儲存。
3. 選主紀錄查看結果；資料異動時畫面會重新計算。

**結果**：同一設定可計算不同客戶；結果不會寫回或覆蓋原始欄位。

**留意**：這是限定的彙總計算，不是可輸入任意 Excel 或程式碼的公式欄位。

## 參數範本（N07）

**用途**：把固定文字變成可填欄位的範本，並帶入日期、剪貼簿或所選紀錄。

**適用情境**：經常回覆相似訊息，但客戶、主旨或日期每次不同。

**例子**：範本為「{{record.title}} 您好，關於 {{subject}}，我們將於 {{today}} 回覆。」；選客戶 A 並填主旨「新報價」，即可預覽完整文字。

1. 先在「參數範本 → 文字範本管理」建立含參數的文字。
2. 在本頁選範本及紀錄，填寫動態出現的參數欄位。
3. 按「預覽內容」，核對後按「複製內容」；Windows 亦可明確選擇貼到前一視窗。

**結果**：同一範本產生不同內容，缺少必要參數時會停止產生。

**留意**：複製不會自動傳送訊息；原生貼上若無法確認目標，文字仍保留於剪貼簿。

## 條件規則（N08）

**用途**：用 AND／OR 群組描述檔案條件，檢視每條規則為何符合，以及多規則的目的地衝突。

**適用情境**：整理報價、合約或報表時，單純副檔名篩選不足，或擔心同一檔案被分到不同資料夾。

**例子**：設定「副檔名＝pdf AND（檔名包含『報價』OR『合約』）」；若另一條規則把同一 PDF 指向不同目的地，預覽會標出衝突。

1. 先在工具箱建立整理規則，設定前綴、目的地及標籤。
2. 在本頁選規則，建立 AND／OR 條件樹並儲存。
3. 選來源後按「檢查所有規則與衝突」，核對解釋，再前往整理規則套用。

**結果**：每個來源都能查看實際值與符合結果；使用者選擇要套用的規則。

**留意**：儲存條件樹不會立即整理檔案；目的地衝突不會自動決定優先順序。

## 追蹤變更（N03）

**用途**：比較同一 Everything 搜尋前後的快照，查看新增、移出結果、屬性變更及可能改名。

**適用情境**：持續留意客戶資料夾、最近修改文件或某類檔案，而不想每次靠記憶比較清單。

**例子**：追蹤「客戶 A 最近 7 天的 PDF」；第一次建立基準，下一次檢查可看到新增的兩份報價及可能改名的文件。

1. 先建立 Everything 追蹤搜尋，再在本頁按「立即檢查」建立基準。
2. 稍後再次檢查，或自行啟用背景監控。
3. 查看差異及最近變更紀錄，確認後標示已讀。

**結果**：變更內容保留供檢視；背景監控在程式執行期間每分鐘循序檢查。

**留意**：「移出結果」不一定代表刪除，也可能不再符合日期條件；截斷或略過的結果不是完整磁碟清單。

## 作業中心（N01）

**用途**：把搬移排入可跨重啟保存的佇列，在背景執行，並集中查看既有改名／搬移歷程與依序復原。

**適用情境**：需要分批整理多組檔案，或希望改錯時逐步回到之前的檔名與位置。

**例子**：把下載資料夾的報價排到客戶 A，再把另一批合約排到封存資料夾；核對後執行。若連續改名三次，可從最新一次開始逐步復原。

1. 選來源和目的地，按「加入搬移佇列」。
2. 按「執行待處理佇列」核對確認；需要時要求安全取消或批次後暫停。
3. 在歷程由最新可復原作業開始，按順序逐批復原。

**結果**：佇列跨重啟保留，但不會在啟動時自動執行；改名及搬移共用歷程。

**留意**：取消須等待安全檢查點；檔案被外部修改或取代時會拒絕復原。不是檔案內容的版本備份。

## 重複檔（N10）

**用途**：先依大小分組，再比較檔案內容雜湊，找出內容相同的副本。

**適用情境**：下載、Email 附件及備份資料夾累積許多副本，想確認哪些內容真的相同。

**例子**：「報價.pdf」與「報價(1).pdf」名稱不同但內容相同，會在同一組；相同名稱而內容不同的檔案不會因此視為相同。

1. 選檔案或資料夾，按「開始分析」。
2. 逐組核對，明確勾選不需要的副本；每組至少保留一份。
3. 確認後移至資源回收筒；執行前會重新核對副本及保留檔案。

**結果**：只回收人工選取並通過核對的副本，預設不勾選任何檔案。

**留意**：不會自動刪除或改為永久刪除；分析可取消。

## 檔案比較（N11）

**用途**：唯讀比較兩個文字檔的逐行差異，或兩個資料夾的相對路徑與檔案內容。

**適用情境**：收到新版文字內容，或想檢查兩個資料夾是否一致。

**例子**：比較「合約初稿.txt」和「合約修訂.txt」，查看新增／移除行；亦可比較「本月報表」與「上月報表」資料夾，找出單邊或內容不同的檔案。

1. 選兩個文字檔，或兩個資料夾。
2. 按「開始分析」。
3. 查看左右差異與狀態，需要的修改再由原工具處理。

**結果**：來源保持不變，不會自動合併或覆寫任何檔案。

**留意**：文字支援 UTF-8／UTF-16，每邊最多 2 MiB、2,000 行；不是 Word／PDF 版面比較。

## 離線 OCR（N12）

**用途**：把圖片中的文字辨識出來，人工校正後連同來源保存為草稿。

**適用情境**：收到掃描收據、截圖或拍照文字，想減少重新打字。

**例子**：選一張收據 JPG，辨識後核對日期及「9,800」等金額，修正錯字，再存入收件匣，之後轉到費用或跟進紀錄。

1. 選一張支援的圖片，語言留空使用系統語言，或填入語言代碼。
2. 按「辨識圖片」，需要時用來源的「預覽」對照原圖。
3. 校正文字後按「校正完成，存入收件匣」。

**結果**：保存可再整理的草稿與圖片來源，沒有自動寫入金額等工作區欄位。

**留意**：需要 Windows 10／11 及可用 OCR 語言元件；辨識可能有誤，須核對。原生功能仍需實機驗收。

## 自動流程（N13）

**用途**：以紀錄新增／更新或手動執行為觸發，通過條件後設定欄位、建立草稿或提醒。

**適用情境**：有固定的資料處理步驟，希望減少重複操作。

**例子**：跟進紀錄新增後，若「已完成＝false」，建立 60 分鐘後的提醒；先選現有紀錄手動預覽，確認條件與動作，再啟用新增事件。

1. 選表格、觸發方式、條件及單一動作，先以手動方式測試。
2. 選紀錄按「預覽動作」，核對符合項目後明確執行。
3. 需要自動執行才啟用事件；到執行歷程檢查結果。

**結果**：留下執行紀錄；動作不連鎖觸發其他流程，匯入、共享接收及還原不觸發。

**留意**：「更新」會在每次紀錄更新後判斷目前條件，不只判斷某欄位由未完成變為完成；仍符合條件的後續更新可能再次執行。

## 操作內目的地快選（N14）

**用途**：快速選用最近使用或已收藏的資料夾，減少重複瀏覽磁碟。

**適用情境**：經常把匯出或搬移結果放到幾個固定位置。

**例子**：先選收藏中的「客戶 A／報表」；稍後從工作區匯出 Excel，儲存對話框會以這個最近位置開始。

1. 在「工具箱 → 其他工具 → 作業中心」的輸出目的地，從最近使用、收藏或瀏覽選擇資料夾。
2. 在搬移佇列使用所選目的地，或前往應用程式的匯出入口。
3. 在原生儲存對話框最後核對資料夾與檔名。

**結果**：保留最近 12 個資料夾，應用程式自有匯出／另存入口可沿用最近位置。

**留意**：只選目的地不會搬移檔案；不接管其他 Windows 程式的儲存對話框。

## 備份（N02）

**用途**：保存工作區、草稿、工具與流程設定，並核對歷史／附件涵蓋範圍及試還原結果。

**適用情境**：大量匯入、修改表格、換電腦或整理資料前，先留下可還原版本。

**例子**：匯入客戶 Excel 前，建立包含草稿、紀錄歷史及可封裝 PDF 的備份；先試還原。匯入結果不符預期時，預覽並確認還原該份備份。

1. 開啟工具箱「備份」，選擇是否包含歷史及紀錄文件，建立備份。
2. 檢查未封裝原因，需要時匯出到另一個可靠位置，並按「試還原」。
3. 真正還原前核對資料數量與涵蓋清單，再確認還原；系統會先備份目前狀態。

**結果**：試還原使用獨立暫存資料庫，不改變目前資料；真正還原會取代相應的應用程式資料。

**留意**：不是整部電腦的備份；資料夾內容不封裝，附件有大小／數量限制，未封裝文件仍為連結。
