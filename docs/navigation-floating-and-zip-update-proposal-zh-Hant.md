# 導覽、浮動工具修正及 ZIP 更新助手提案

## 已實作

- 頂部順序：首頁 → 資料工作區 → 我的收藏 → 日曆／看板 → 查看紀錄 → 檔案 → 工具箱 → 搜尋。
- 「檔案」選單保留 Everything 追蹤及檔案工具。開啟子頁後，選單標題顯示目前頁面；原有快捷鍵與頁面控制器沿用。
- 設定與資訊集中於右側齒輪選單。選單支援鍵盤、Escape、點擊外部關閉，以及切換頁面後回到可見的導覽入口。
- 工具箱的其他工具全部直接顯示，不再收合。
- 新式入口中的 B 按鈕統一為圓形；側邊工具列、四邊 Dock 與懸浮球仍保留各自操作方式。
- 新式入口的透明區域原本仍屬原生矩形視窗，會攔截底下主程式或其他程式的滑鼠操作。Windows／Linux 改為只保留快捷面板及入口的原生視窗區域；懸浮球依圓形切分區域。設定或其他對話框開啟期間暫時恢復完整區域，關閉後還原，避免對話框按鈕被切掉。傳統模式恢復完整視窗區域。
- 設定 → 浮動工具 → Floating Workspace 2.0，可分別指定常用文字、剪貼簿、工作情境、檔案、日曆及草稿的面板寬高。浮窗內設定也提供相同欄位。
- 自訂寬度 380–1600、高度 360–1200，採 DIP。快捷面板的數值代表內容面板尺寸，額外預留入口與間距；獨立工具使用相同自訂尺寸。套用至目前工具及已開啟的獨立視窗，螢幕不足時自動限制。還原自動尺寸會清除固定偏好並沿用目前尺寸，之後可自由拖曳調整。
- 這次新增的是各工具的面板尺寸。清單列高、圖示大小等仍使用原有設定，未新增任意內部元件的自由縮放。

## ZIP 更新助手：待討論的功能，尚未實作

### 建議開發

適合經常把「只包含修改檔案」的 ZIP 套用至現有專案的工作。入口放在「檔案工具」內，不新增頂部頁籤。核心流程只處理從 ZIP 單向套用至目的地；內容逐行合併及雙向同步另行評估。

### 第一版使用流程

1. 拖入或選擇 ZIP，左側顯示檔案樹及大小。
2. 選擇右側目標資料夾；提供最近目的地及可命名的常用目的地。
3. 明確選擇 ZIP 內的來源根目錄，顯示「包內相對路徑 → 完整目標路徑」預覽。若偵測到單層包裝資料夾，只提出建議，不默默改變映射。
4. 掃描包內檔案，分類為新增、內容不同、內容相同及無法處理。大小相同不代表內容相同；日期只作輔助。相同內容預設略過，對差異檔案可逐項勾選。
5. 確認所選新增／覆寫清單、目的地及備份位置，再執行。目標中未出現在 ZIP 的檔案一律保留。
6. 覆寫前先保存原檔及還原清單；完成後列出新增、覆寫、略過、失敗及備份位置，提供開啟目的地及檢視記錄。

### 路徑對應例子

| ZIP 相對路徑 | 選擇的目標根目錄 | 寫入位置 |
| --- | --- | --- |
| els1104/els1104_form.dart | C:\project\lib\modules\learning | C:\project\lib\modules\learning\els1104\els1104_form.dart |
| els1104_form.dart（已選 ZIP 內 els1104 為來源根） | C:\project\lib\modules\learning\els1104 | C:\project\lib\modules\learning\els1104\els1104_form.dart |

兩種方式均可，但必須預覽最終路徑，不能同時多加一層 els1104。

### 複雜度與邊界

這是中等複雜度功能。解壓並複製本身不難；可靠覆寫、路徑映射、保留原資料及錯誤復原佔主要工作。

- 只接受可處理的 ZIP；先限制檔案數與總解壓大小。第一版不支援加密、多卷、RAR 或 7z。
- 預先拒絕跳出來源根的路徑、Windows 不合法／重複名稱、檔案與資料夾衝突及連結；目標 junction／symlink 也需確認不會寫出選定範圍。
- 寫入前再次確認目標仍與預覽時一致；變更的項目停止，要求重新預覽。
- 若檔案鎖定、空間不足或存取失敗，明確報告成功及未完成項目。取消只停止後續項目；不可宣稱整批是原子交易。
- 還原前也需核對更新後檔案是否再被修改，避免覆蓋使用者後續工作。
- 本機目的地先行；內網共享路徑必須沿用現有離線／內網政策，另驗證斷線與部分寫入的處理。

建議先完成上述第一版，再按實際需要加入文字差異預覽或呼叫外部比對工具。

## 驗證與限制

新增回歸測試涵蓋原生區域幾何、透明間距、懸浮球角落、對話框生命週期、模式切換、各工具尺寸保存／驗證及獨立視窗更新。

自動測試及應用程式契約檢查通過。執行環境未能啟動 Chromium 視覺測試；未完成 Windows Electron 實機、不同 DPI／多螢幕、其他程式在底下時的點擊驗收，也未產生 Windows EXE。
